# 给Mac做的文件管理器，又更新了

做 WinFile 的时候，我想把自己熟悉的 Windows 文件管理习惯，带到 Mac 上。

最近收到一条建议：「添加收藏能不能少点几次，也别再弹系统文件选择器了？」

这次 1.2.0，就把这件事补上了👇

📂 收藏可以直接拖了
把文件夹拖到左侧个人收藏区，就能加上快捷入口；也可以右键添加当前目录，支持多选和去重。原文件夹不会被移动或复制。

🪟 添加文件夹，用自己的弹窗
现在不用再调系统选择器。在 WinFile 里双击浏览、输入路径、筛选目录，还能显示隐藏文件夹、同级多选。取消后，主页面仍停在原来的位置。

🔄 后续更新不用反复下载
启动时检查新版本，可选「安装更新」「跳过此版本」「稍后提醒」。下载后校验签名，确认安装并重启；有文件任务时会等它完成。
注意：1.1.0 及更早版本，需要先手动升级到 1.2.0 一次。

🛠️ 也修了一个影响日常使用的问题
针对切换应用、双击文件打开其他软件时的崩溃做了修复。Apple Silicon 和 Intel/Rosetta 的应用包测试各通过 776 项。

之前的功能也都还在：
💬 微信已下载附件筛选、占用统计与清理，不解密聊天数据库。
📱 USB + adb 查看安卓公共存储，上传、下载和整理文件，需要授权 USB 调试。
📦 ZIP / RAR / 7Z 等格式解压，支持密码、分卷和批量处理，同名文件保留两者。

支持 macOS 13+，Apple Silicon / Intel。
项目已开源，GitHub 搜：fakerUZI/macos_winfile，1.2.0 已发布。

如果你也习惯 Windows 的文件管理方式，欢迎试试，哪里不顺手也可以继续提。
