# 给Mac做了个能清微信的文件管理器

最近一直在完善自己做的 WinFile：一个 macOS 上的 Windows 风格文件管理器。把我日常最常用的三件事放到了一起👇

💬 微信文件清理
查看已经下载到 Mac 的聊天附件，按文件名、类型、大小、时间筛选。
顶部直接显示全部附件、当前筛选、已选文件各占多少空间，还能按类型和月份看分布。
双击打开、空格预览，找到大文件后可以在新页签打开所在文件夹。清理前需要确认，文件会移到废纸篓；不读取或清理聊天数据库。

📱 Mac 查看安卓文件
手机或平板通过 USB 连接后，在左侧进入设备目录，查看文件夹、上传和下载文件，也支持重命名等常用操作。
需要先安装 adb，并在设备上开启、授权 USB 调试；可访问范围仍受设备权限限制。

📦 解压也一起补齐了
支持 ZIP、RAR（含 RAR5）、7Z、TAR 等格式，内置 7-Zip，无需另外安装解压引擎。
支持密码、分卷、批量解压、独立输出目录和取消。同名文件保留两者，避免直接覆盖。

另外还有中英双语、多页签、固定/恢复页签、批量重命名预览、大小/日期组合搜索和重复文件查找。

支持 macOS 13+，Apple Silicon / Intel 都能用。项目开源，GitHub 搜：fakerUZI/macos_winfile，README 已补一键安装命令。

配图使用示例附件和设备公共目录，不含真实聊天内容。微信只扫描已下载到本机的附件，不解密聊天记录。
