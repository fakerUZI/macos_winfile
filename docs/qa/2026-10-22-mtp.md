# Android 文件访问迁移到 MTP

> 发布归档：以下为开发过程的原始验收记录，其中“未发布”和旧版本号描述当时状态；最终代码随 v1.4.0 (10) 发布。视频最终行为以 [内存流式播放记录](2026-10-22-mtp-streaming.md) 为准。

日期：2026-10-22。范围：当前本地源码；未提交、未推送、未发布新版本。

## 实现

- 只保留 MTP：删除 AdbRunner、ADB 设备枚举、shell 目录解析与相关安装/USB 调试提示。
- 内置 libmtp 1.1.23、libusb 1.0.30 和双架构 WinFileMTP 辅助程序；固定下载源与 SHA-256，动态链接并随应用签名。用户不需要 Homebrew、ADB、驱动或开发者选项。
- JSON 请求传递设备序列号、当前 USB 连接标识、存储 ID 和对象 ID。路径逐级解析为 MTP 对象，不拼接 shell 命令。不同设备不共享文件缓存。
- 每次文件操作独占一个 MTP 会话；同进程请求串行。独立描述符探测不占用传输接口，持续检查插拔；断开清空旧目录，重连自动恢复；未解锁/未允许文件传输时重试。超时、取消可终止辅助程序，主窗口保持响应。
- libmtp 默认关闭安卓会话时强制重置 USB，真机连续操作暴露了因此产生的 USB 地址变化。本项目应用 `native/vendor/mtp/no-usb-reset.patch`，保留 CloseSession、接口释放和句柄关闭，移除强制整机 USB 重置。补丁及构建脚本和许可证随应用分发。
- 上传和下载拒绝覆盖同名目标，上传拒绝符号链接；下载先写私有暂存区，成功后移动到最终位置。复制经本机临时目录下载并上传，保留原文件；设备内移动仅使用设备支持的 MTP MoveObject，失败不自动复制后删除。
- 多选下载顺序处理，上传下载可取消。双击及空格预览先完整下载只读副本，然后使用 Mac 默认程序/Quick Look。视频尚不支持边下载边播放，编辑不会回传手机。
- 打开缓存包含连接、存储/对象 ID、路径、大小、修改时间；无修改时间时不复用旧缓存。缓存软目标 2 GiB，保留当前会话打开的副本。

## 可重复执行

```bash
./native/run_native_tests.sh --cli-only
python3 native/WinFileTests/test_mtp_helper.py \
  --helper native/native-build/mtp/WinFileMTP
./native/build_native.sh --in-place
```

不连接设备的逻辑测试可使用 `--skip-device-tests`。真机协议脚本需要手机解锁并选择 USB 文件传输；只对自身创建的 UUID 测试目录执行写入及删除。

## 验证边界

MTP 可见范围、设备内移动能力、锁屏行为由手机实现决定。当前只验证一台真实安卓手机；未覆盖所有品牌和 SD 卡。64 位大小由模型回归覆盖，尚未向真机完整传输大于 4 GiB 的文件。截图使用生成样例，不打开个人文件。

## 联想平板目录返回上级失败回归

用户反馈设备曾无法打开，随后确认已恢复。本轮识别到联想小新平板 Pro GT（USB 17ef:7f5c），能进入存储及 Download。此前连接短暂失败的原因未证实。

另复现到独立的目录导航错误：在 Download 中点击“向上”后，提示“设备上的项目已不存在”。`URL.deletingLastPathComponent()` 生成 `/storage-65537/`；Objective-C 的 `NSString.pathComponents` 把末尾 `/` 当作额外组件，helper 尝试查找名为 `/` 的子项目。修复前独立协议检查确认：同一设备 `/storage-65537` 能列出 19 项（含隐藏项），`/storage-65537/` 返回 `notFound`。

修复：AndroidURL 创建和拆分统一移除空的路径分隔组件；helper 在拒绝 `.` 和 `..` 后同样规范化，兼容历史 URL、返回上级和重复分隔符。没有折叠路径穿越组件，也没有重试可能改变文件的操作。

- 命令行回归：1,096 项通过，0 失败（`--quick --skip-device-tests`）。新增父目录 URL、大小写、根路径、重复分隔符、路径穿越保留、面包屑测试。

- 默认的特殊字符文件名测试在该平板上传时失败，libmtp 返回 PTP 2002 General Error；普通 sample.txt 成功。保留默认特殊字符测试，增加显式 `--filename` 参数以便区分设备文件名兼容性；不能宣称该平板已通过全部特殊字符测试。所有唯一测试目录均由 finally 清理。
