# LeafFiles 2.1.0 发行验收

版本 `2.1.0`，构建号 `18`。macOS 15.8.1，Apple Silicon 本机验证，并使用 Rosetta 验证 Intel 可执行文件。应用源码与官网继续由 `main` / `codex/website` 分支分别维护。

## 发行范围

- 压缩包在访达的「打开方式」注册为 LeafFiles 备用查看器；接收冷启动和运行中的文件打开请求。
- 「在 LeafFiles 中显示」系统服务，在新页签定位文件或浏览文件夹。
- 应用菜单和顶级菜单栏跟随中英文选择；处理重复设置项与 Help 标题重置。
- 内置目录选择器支持新建、进入及确认解压目标，处理名称、冲突与权限错误。

完整功能实测见 [访达与菜单语言](2026-10-25-finder-integration-language.md) 和 [解压新建目录](2026-10-25-extraction-new-folder.md)。

- 最终包深度、严格代码签名校验通过；通用可执行文件包含两个架构。
- arm64 bundle 逻辑检查：**1320 通过，0 失败**。
- Intel / Rosetta bundle 逻辑检查：**1320 通过，0 失败**。
