# LeafFiles 配色更新

> 本文记录该轮验证时的状态；最终 2.0.1 构建、配色与发布结果以[发行验收记录](2026-10-24-release-2.0.1.md)为准。

> 历史记录：本轮自定义绿底和渐变已按后续反馈撤回，当前界面恢复系统原生配色，详见同日 native-style 验收记录。

使用单一叶绿主色及同色系灰绿层次，主要调整应用导航、页签、主页磁贴、详情栏、解压预览、搜索、清理与安卓设备页面。文件本身的系统图标与警告/删除的语义颜色保留。

浅色：灰绿导航与工具栏、米白画布、近白卡片、浅绿选中区。深色：森林炭灰背景、灰绿卡片、柔和叶绿重点。

主要绿色文字与卡片底色的 sRGB 对比度：浅色 6.11:1，深色 5.23:1。增加对比度模式下，通用面板边框保持系统分隔线完整强度。

本轮仅调整视图颜色与装饰，不改变扫描、解压、安卓传输等业务逻辑。

已完成的视觉检查：中文浅色主页、中文浅色通用清理、英文深色紧凑通用清理，以及中文解压预览的双击打开和内嵌 Quick Look。截图使用生成的示例文件。

验证结果：arm64 / x86_64 优化构建通过，macOS 13 最低目标不变；包签名校验与 git diff --check 通过。已更新 /Applications/WinFile.app 并启动，原有三个页签与软件清理/微信选择恢复。本轮纯视图样式调整，未新增业务逻辑测试。未提交或发布。
