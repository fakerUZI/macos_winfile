# LeafFiles 2.2.0 发行验收

版本 `2.2.0`，构建号 `19`。应用源码由 `main` 维护，官网由 `codex/website` 独立维护。

## 发行范围

- 恢复侧栏导航与分类图标配色，主页快速访问采用相同的蓝、绿、橙、紫色语义，保留文字和背景层次。
- 左右分隔线增加方向箭头，收起后保留反向展开箭头；恢复用户之前调整的宽度，边条独立占位。
- 拖动调宽、双击复位、顶部按钮与辅助功能入口继续可用；空间清理不显示不适用的右侧展开入口。
- 文件列表和网格首帧使用 macOS 文件夹图标，消除黄色占位闪现，继续异步读取自定义图标。

## 最终发行构建

- 使用 `native/build_native.sh` 相同源码、编译选项与组装步骤，在临时脚本中并行完成 arm64 / x86_64 正式优化构建。仓库构建脚本不变。
- 通用应用包含两个架构；深度、严格代码签名校验通过。
- 最终 arm64 bundle：**1320 项通过，0 失败**。
- 最终 Intel / Rosetta bundle：**1320 项通过，0 失败**。
- 真实窗口冒烟：**44 项断言通过**，覆盖页签切换、内容缓存、虚拟网格复用、悬停状态与扫描提示布局。测试工具的模拟双击段没有命中目标，不将该段作为双击通过证据。
- 更新签名与篡改拒绝：**4 项通过**；隔离安装、备份、迁移及失败回滚：**11 个场景通过**。
- Info.plist、本地化字符串、Shell 语法与 Git 空白检查通过。跳过真实安卓设备文件读写。

## 本机交互验收

以下检查使用版本号调整前的同源功能构建完成：

- 左右侧栏分别收起、同时收起；窗口边缘保留方向相反的展开按钮。
- 右侧通过边缘箭头恢复到先前的 **284 点**，左侧恢复到先前的 **236 点**，确认展开没有丢失宽度偏好。
- 左右拖动方向正确，双击分别恢复 **216 / 264 点**默认值，顶部按钮可继续操作。
- 展开与收起的边条单独占位，文件内容和滚动条没有被覆盖。
- 主页 8 个快速访问入口正常显示；浅色与深色真实视图快照已检查，媒体入口配色呼应侧栏。
- 验收使用独立生成的示例目录；结束后关闭临时页签并恢复用户当前页签。
