# 解压位置选择器新建文件夹验收

环境：macOS 15.8.1，Apple Silicon。基于当前未提交修改继续修复，未发布新版本。

## 行为

- 共用的内置目录选择器左下方新增「新建文件夹…」，同时适用于解压位置、打开文件夹和收藏目录选择。
- 创建成功后自动进入新目录，清空旧的选择与筛选；确认「选择此文件夹」后才开始解压。可以连续创建多级目录。
- 创建操作在后台执行，期间禁用重复提交和导航。非法名称保留输入窗口并显示错误；同名目录、文件和失效符号链接均视为冲突。
- 使用原子 mkdir，避免把已存在的目录误判为创建成功。拒绝空名称、`.`、`..`、路径分隔符、NUL 及不可浏览的应用包名称。只读位置禁用新建，创建失败保留当前目录并提示原因。

## 检查

- arm64 / x86_64 正式优化构建及深度签名校验通过。
- 应用包逻辑检查：**1320 项通过，0 项失败**，包含名称校验、同名保护、只读错误、清空旧筛选选择、连续新建目录与实际解压到新目录。
- 本机实际界面：双击测试 ZIP → 解压全部 → 解压到… → 新建文件夹。
- 输入 `../不应创建`：显示「名称不合法」，继续停留在命名窗口，未创建越界目录。
- 修改为「新建 解压目录」：成功创建并自动进入该目录；点击「选择此文件夹」后完成 2 项解压，失败 0 项。
