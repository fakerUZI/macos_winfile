# Finder 入口与菜单语言验收

日期：2026-10-25。环境：Apple Silicon，macOS 15.8.1。基于 2.0.4 / 构建 17 的本地修复，未发布新版本。

## 变更

- 注册支持的压缩包类型为备用查看器，不改变用户选择的系统默认解压应用。
- Launch Services 传入压缩包时，新建页签并打开内置预览；冷启动请求等待实际浏览窗口登记后处理，保留恢复的页签。普通文件只定位，避免默认应用指向 LeafFiles 时循环调用。
- 注册「在 LeafFiles 中显示」系统服务：接受本地文件、文件夹和多选，兼容文件 URL 与旧版文件路径剪贴板。文件在新页签定位并选中，文件夹在新页签浏览。
- 应用菜单使用可动态本地化的 About / Settings / Hide / Quit 命令。macOS 14+ 使用 SettingsLink，macOS 13 保留对应的设置窗口动作。隐藏系统额外生成的重复设置项。
- 菜单栏顶级标题同步更新子菜单标题；观察当前顶级菜单的标题变化，避免 SwiftUI 将 Help 重置回启动语言。替换菜单后释放旧观察。
- 新增生成菜单的 `--selftest-native-menus <日志路径>` 检查。中英文资源加入对应菜单及服务文案，构建脚本复制 ServicesMenu.strings。

## 验证结果

- 正式优化构建成功：arm64 + x86_64，完整深度签名校验通过。macOS 13 分支完成编译；本机实际界面验证为 macOS 15.8.1。
- 最终 bundle 逻辑检查：**1301 项通过，0 项失败**。
- 生成菜单的中英切换检查通过；独立真实 SwiftUI 窗口中，将 Help 子菜单标题再次设为中文后会立即恢复为英文。
- 真实窗口冒烟检查：**44 项断言通过**，覆盖页签、内容缓存、1200 项网格循环复用、悬停清理和扫描提示布局。日志中的模拟双击段未命中目标，不作为双击通过证据。
- 访达真实右键：ZIP 的「打开方式」可见 LeafFiles；在应用未运行时选择它，可直接进入压缩预览并看到测试包中的文件。原有页签保留。
- 访达真实右键：Markdown 文件的「在 LeafFiles 中显示」可新建页签并选中目标；不会启动文本编辑器。
- ZIP 的系统默认打开应用在修改前后均为系统「归档实用工具」。
- 最终安装实例实测中 → 英 → 中 → 英，File / Edit / View / Go / Window / Help 顶级标题即时切换；应用菜单的 About、Settings、Hide、Quit 均为英文，Settings 仅一项。
- `⌘,` 能打开设置，`⌘T` 能新建页签；关闭页签菜单及标签关闭动作有效。验收后恢复用户的中文偏好与原有页签。
- 临时测试应用已取消系统登记并清理，正式安装保留在 `/Applications/LeafFiles.app`。未操作实际安卓文件。

## 范围说明

应用菜单与顶级菜单栏跟随 LeafFiles 的语言选择；少数由系统直接提供的窗口命令、输入法、听写及第三方服务文案仍可能采用系统语言。访达中的服务名称也由系统语言选择。

验收日志及英文应用菜单文本保存在本机 `~/.codex/visualizations/2026/10/25/leaffiles-finder-integration/`。
