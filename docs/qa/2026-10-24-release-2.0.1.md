- `native/build_native.sh --in-place` 优化构建成功，产物为 `LeafFiles.app`，版本 2.0.1 / 构建号 14，包含 arm64 与 x86_64；完整包签名校验通过。
- 独立测试副本使用隔离的偏好设置域。Apple Silicon：**1,239 项通过，0 失败**；Intel/Rosetta：**1,239 项通过，0 失败**。
- `tools/test_update_package.py`：**4 项通过**，覆盖有效签名、归档篡改、更新源篡改及虚假长度拒绝。
- `tools/test_installer.py dist/WinFile.zip`：**11 个场景通过**，覆盖首次安装、备份、摘要/签名拒绝、运行保护、回滚、旧名迁移、双目录合并及符号链接拒绝。
- 归档顶层只有 `LeafFiles.app`，Info.plist 版本/构建号正确；签名 appcast 包含 @KaKi87 致谢和 issue #3 链接。
- 中英资源与 Info.plist 格式校验、shell 语法及 `git diff --check` 通过。
- 下载文件继续使用 `WinFile-2.0.1.zip` 与 `WinFile.zip`，更新源与 Ed25519 密钥保持不变。
