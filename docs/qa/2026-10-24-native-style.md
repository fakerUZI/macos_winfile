# LeafFiles 恢复原生配色与按钮细节调整

> 本文记录该轮验证时的状态；最终 2.0.1 构建、配色与发布结果以[发行验收记录](2026-10-24-release-2.0.1.md)为准。

按用户反馈撤回自定义绿色背景、渐变和全局强调色覆盖。背景、面板、分隔线和强调色重新使用 macOS 系统语义颜色，随系统深浅外观和强调色变化。

- 清理统计数字恢复正文色；工具页面标题图标移除大块彩色底座，统一尺寸与线条。
- 工具栏普通操作使用中性色，删除仅在悬停/按下时强调红色；禁用状态与普通状态有区分。
- 新建使用简洁加号，更多工具减少装饰圆框；筛选标签使用浅中性底色。
- 保留详情栏分组、固定操作区、目录导航和窄窗口布局改进。

本轮仅修改视觉呈现，未改变扫描、解压和文件传输逻辑。
