# 扩展解压格式与压缩包预览回归

## 行为

- ZIPX 接入本机压缩包识别、分类、解压与预览；支持数字分卷入口，保留已有 ZIP / 7Z / RAR 行为。
- 新增 Zstandard、LZMA、Unix compress、CAB、ARJ、LZH/LHA、CPIO、AR、DEB、RPM、XAR；DEB / RPM 保留软件包分类，解压不执行安装。
- 本机单选压缩包可通过双击（自定义默认应用优先）、空格或右键「预览压缩包」打开内置窗口，筛选相对路径、查看原始/压缩大小、算法与加密状态。
- 预览中的「解压」捕获当前包的 URL，主窗口后来改变选择不会改变解压来源；自选目录使用内置选择器。
- 单文件查看只临时解出所选普通项，禁止把文件夹或链接交给查看器；大小上限 64 MiB，副本权限 0400，使用嵌入式 Quick Look，不调用 NSWorkspace 打开外部应用。
- 普通包列目录不解压。压缩 TAR 目录预览需在私有目录展开一层中间归档，上限 512 MiB；原始大小未知时同样监控输出并核对实际大小。普通解压不受预览大小限制。
- 列目录限制 32 MiB 输出 / 100,000 项；字段歧义、异常大小与不安全路径明确报错。进程运行期间检查输出限额，超限/关闭时取消、终止子进程，并等待其退出后删除工作区。
- 所选成员按字面路径提取，禁用通配符；提取前复查列表及压缩包文件身份、大小和修改时间，提取后复查并验证实际文件类型和大小。
- 原有暂存提交、防覆盖、路径校验和子进程写入隔离继续使用。普通 Store/Deflate ZIP 保留 ditto 元数据路径；使用扩展算法的 ZIP 转给 7-Zip，避免错误走 ditto。

- 最终构建实际重复「先选 TAR.ZST，再右键 CAB」，预览标题为 CAB，右键解压输出为 CAB 的独立目录，均未误用 TAR。

## 样本与范围

真实 ZIPX/CAB/LHA/Zstandard 样本固定到 libarchive 提交，来源、SHA-256 和许可见 `native/WinFileTests/Fixtures/README.md`。其余样本在测试临时目录生成，不含用户数据。

ARJ、DEB、RPM 的识别与引擎格式支持已核对，尚未覆盖其所有真实压缩/加密/分卷变体；不宣称支持所有 ZIPX 专有算法。Quick Look 的可呈现内容取决于系统和已安装的预览扩展，不能预览的内容可正常解压后处理。
