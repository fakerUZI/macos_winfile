# WinFile v1.3.0

本次更新将清理能力扩展到多种软件，并把通用清理与软件清理合并为侧边栏底部的「空间清理」入口。

## 新功能

- **通用清理**：扫描明确的应用缓存、日志、下载与桌面安装包，以及个人目录中的大文件。支持按类型、来源、文件名和路径筛选，提供实际分配空间估算、目录分布、200 行分页和跨页选择。
- **软件清理**：在同一个选择器中选择微信、Chrome、Edge、Brave、VS Code、Slack、Discord、Teams 等具有可读取清理目录的软件。微信保留独立的聊天附件扫描、账号、月份、类型和大小筛选；其他软件仅扫描其已识别缓存及日志。隐藏未解析的 bundle 标识及辅助、更新、扩展子程序。
- **清理控制**：默认不勾选文件，缓存、日志与安装包默认保留最近 7 天；支持忽略文件或目录、最近 30 条本机清理摘要、取消扫描和明确的不完整结果提示。大文件默认阈值为 100 MB，可在应用内选择个人子目录。
- **文件操作**：清理结果支持双击打开、右键预览及复制路径，在新页签打开所在目录。会话恢复兼容旧微信清理页签，并保留软件子范围选择。

## 保护与恢复

- 扫描不修改文件；清理仅将明确确认的文件移到废纸篓，不提权、不清空废纸篓。
- 执行前复查文件与目录身份、大小和修改状态。跳过运行中的应用、占用或无法确认状态的文件，以及数据库、凭据、持久数据、受保护缓存、符号链接和硬链接。
- 通用清理与其他软件的缓存/日志清理可在当前会话使用 `⌘Z` 撤销。微信附件沿用独立流程，可从废纸篓恢复，不纳入全局撤销。
- 清理执行期间阻止切换清理子范围，应用更新重启会等待当前文件操作结束。
- 移到废纸篓不会立即释放可用空间；占用统计受 APFS 共享块等因素影响，仅作估算。

## 修复

- 修改搜索、类别或来源筛选后，清除旧勾选和待确认清单，避免保留不可见项目。
- 成功清理后同步更新扫描占用和目录分布，按实际分配空间扣减，不重复扣减父子目录分组。
- 全局撤销恢复文件后，自动刷新通用清理列表。
- 重复文件查找遇到符号链接时，不再连带漏扫相邻真实目录；继续排除硬链接重复计数。
- 清理入口使用系统默认文字颜色，统一页签标题、图标与侧边栏高亮。

## 验证

- Apple Silicon 与 Intel/Rosetta 应用包分别 **921 项通过，0 项失败**，包括文件操作、收藏、会话恢复、中英文资源、微信及通用清理、RAR/7z 解压、重复文件查找和安卓逻辑。
- 真实页签界面冒烟测试及隔离清理界面验收通过。
- 使用 `--skip-device-tests`，本轮不包含真实安卓设备读写。清理集成测试仅移动生成的临时文件。

## 安装与升级

支持 macOS 13 及以上，提供 Apple Silicon 与 Intel 通用安装包。已安装 v1.2.0 或 v1.2.1 的用户可通过「WinFile → 检查更新」升级；v1.1.0 及更早版本需手动升级一次。

下载 `WinFile-1.3.0.zip` 或 `WinFile.zip`，解压后替换「应用程序」中的 WinFile。也可先退出 WinFile，再运行一键安装命令：

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

安装包与更新源使用原有 Ed25519 更新密钥签名，附带 SHA-256 文件。当前应用仍为 ad-hoc 签名，未进行 Apple 公证；首次打开见 [README 安装说明](https://github.com/fakerUZI/macos_winfile#方式一下载安装包)。

## English

WinFile 1.3.0 adds a unified Storage Cleanup page with General Cleanup and Software Cleanup.

- Scan identified caches, logs, installers and large personal files; inspect usage estimates, filter results, exclude paths and confirm selected files before moving them to Trash.
- Select WeChat alongside other apps. WeChat retains its attachment scanner and filters; other apps are limited to identified caches and logs. Helper components and unresolved bundle identifiers are hidden.
- Keep recent caches, logs and installers by default; recheck file identity, modification and usage before cleanup. Running apps and protected data are skipped. General cleanup and other apps’ cache/log cleanup support undo; WeChat attachments can be recovered from Trash.
- Fix stale hidden selections, stale usage statistics, missing refresh after undo, and skipped sibling directories in duplicate-file scans involving symlinks.
- 921 tests pass in each Apple Silicon and Intel/Rosetta app bundle. Native tab and isolated cleanup UI checks pass. Physical Android device read/write tests are excluded.

Requires macOS 13 or later. Users on v1.2.0 or v1.2.1 can update in the app; earlier versions need one manual upgrade. Both `WinFile-1.3.0.zip` and `WinFile.zip` contain the universal app. The signed update feed and SHA-256 files accompany the release.
