# WinFile v1.5.0

版本 `1.5.0`，构建号 `12`。新增 ZIPX 与更多解压格式，以及应用内压缩包目录和单文件预览。

## 解压格式

- 新增 ZIPX、Zstandard（`.zst/.zstd`）、LZMA、Unix compress（`.Z`）、CAB、ARJ、LZH/LHA、CPIO、AR、DEB、RPM、XAR；软件包仅解出归档内容，不执行安装。
- `.tar.zst/.tar.zstd/.tzst`、`.tar.lzma/.tlz`、`.tar.Z/.taz` 自动解开压缩流与 TAR 两层；保留已有 ZIP、RAR/RAR5、7Z、TAR、GZip、BZip2、XZ 支持。
- ZIPX 数字分卷可从首卷或后续卷进入；传统 `.zipx/.z01` 入口也可定位主卷。已有分卷去重、密码、批量操作、取消和同名不覆盖继续使用。
- 使用扩展算法的 `.zip` 改用内置 7-Zip，普通 Store / Deflate ZIP 保留 macOS 元数据处理。具体算法与加密变体取决于引擎，不宣称支持所有 ZIPX 专有算法。创建压缩包仍使用 ZIP。

## 压缩包预览

- 双击本机压缩包、空格或右键「预览压缩包」，在 WinFile 内查看包内路径、原始/压缩大小、算法与加密状态，可按名称或路径筛选；自定义默认应用优先于双击预览。
- 选中普通文件后点击「查看所选文件」或双击条目，临时解出这一项，通过嵌入式 Quick Look 查看，不自动启动外部应用、不改写原包。副本只读，切换或关闭后清理。
- 预览窗口可直接解压到当前目录、独立目录或自选位置，自选位置使用 WinFile 内置文件夹选择器。
- 修复先选 A、再右键 B 时预览/解压误用 A 的问题；相关菜单使用实际右键目标，目录选择器固定解压来源。

## 限制与验证

- 普通包列目录不解出文件。单文件预览上限 64 MiB，压缩 TAR 预览需临时展开中间归档（上限 512 MiB）；超限可以正常解压后查看。目录列表上限 100,000 项 / 32 MiB；无法安全解析时明确报错。
- 路径与链接校验、子进程写入隔离、取消后等待进程退出再清理、字面成员路径匹配、源包变化复查均保留或补充验证。
- 功能验收：命令行 1,220 项通过，arm64 与 Intel/Rosetta 应用包各 1,225 项通过，均为 0 失败，跳过真实安卓设备操作。真实 ZIPX LZMA / PPMd / Zstandard、CAB MSZip、LHA LH5、TAR.ZST 样本及生成归档通过回归。ARJ、DEB、RPM 未覆盖所有真实变体。
- 最终 1.5.0 (12) 发行构建：arm64 与 Intel/Rosetta 各 **1,225 项通过，0 失败**（跳过真实安卓设备操作）；签名及篡改拒绝 4 项、隔离安装及失败回滚 6 项均通过。
- 真实窗口验证预览、筛选、嵌入式文本/CSV 查看、内置目录选择器、输出字节、右键目标隔离与临时文件清理；详见 [验收记录](https://github.com/fakerUZI/macos_winfile/blob/main/docs/qa/2026-10-23-archive-preview.md)。
- macOS 13+，一个通用包支持 Apple Silicon 和 Intel。v1.2.0 起支持应用内检查更新；更新包和更新源使用既有 Ed25519 密钥签名。当前应用为 ad-hoc 签名，未经过 Apple 公证。

## English

WinFile 1.5.0 (build 12) adds ZIPX and more extraction formats, plus built-in archive and single-file previews.

- Extract ZIPX, Zstandard, LZMA, Unix compress, CAB, ARJ, LZH/LHA, CPIO, AR, DEB, RPM and XAR, including additional compressed TAR combinations. Recognize ZIPX split volumes. Package formats are only extracted, never installed; codec variants depend on the engine. Archive creation remains ZIP.
- Double-click a local archive, press Space or choose Preview archive to list and filter paths, sizes, methods and encryption. Custom default apps take precedence for double-clicks.
- View one regular member using embedded Quick Look and a temporary read-only copy. No automatic external app launch or write-back; remove copies on switch/close. Limits: 64 MiB per member, 512 MiB for a compressed TAR intermediate, 100,000 entries / 32 MiB per listing. Larger items can still be extracted normally.
- Extract directly from the preview with the built-in folder picker. Use the actual right-click target and retain the source while selecting a destination. Extended-codec ZIP files use bundled 7-Zip; ordinary ZIP metadata handling is preserved.
- Feature validation: 1,220 logic checks and 1,225 checks each in arm64 and Intel/Rosetta app bundles, all passing with physical-device operations excluded. Public ZIPX/CAB/LHA/Zstandard samples and generated archives cover extraction and preview; real-window checks verify filtering, embedded viewing, destination choice, output bytes, right-click isolation and cleanup. Not every ARJ/DEB/RPM or ZIPX codec variant has a physical sample test.

The final 1.5.0 (12) release builds passed **1,225 checks each on arm64 and Intel/Rosetta**, excluding physical-device operations. Four signature/tamper checks and six isolated installation/rollback scenarios passed.

Requires macOS 13+. Universal Apple Silicon / Intel build; in-app updates available from v1.2.0. The app is ad-hoc signed and not Apple-notarized; existing Ed25519 signatures verify update packages and feeds.
