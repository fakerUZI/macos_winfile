# LeafFiles v2.0.0

版本 `2.0.0`，构建号 `13`。本次主要更新：**界面优化，以及 WinFile 正式更名为 LeafFiles**。

## 界面优化

- 统一页签、工具栏和地址栏的背景、间距与层级，活动页签使用简洁的强调线。
- 侧边栏分组可折叠并记住状态，统一图标与数量标记，空间清理固定在底部。
- 通用清理与微信附件清理突出总量和已选占用，区分扫描、筛选和移到废纸篓的操作。
- 搜索弹窗默认收起更多条件，显示有效条件数量；已有筛选条件会自动展开。
- 压缩包预览根据窗口宽度切换左右或上下布局，支持关闭单文件预览及折叠说明。
- 文件详情增大本机缩略图、分组显示属性并支持复制所在目录；文件图标网格更紧凑。
- 保留简体中文、英文、浅色和深色外观，以及 macOS 13 兼容性。

## 新名称与升级

- 中英文应用名称、菜单、关于页面、帮助及系统权限说明统一使用 **LeafFiles**。
- 原一键安装命令、GitHub 地址和自动更新渠道保持不变。已有收藏、页签会话、设置与缓存继续沿用，无需迁移。
- 为兼容已有安装，磁盘上的应用路径仍为 `WinFile.app`，更新及下载文件仍使用 `WinFile-2.0.0.zip` 与 `WinFile.zip`。请覆盖更新原应用，避免重复安装。
- 微信附件整理、MTP 安卓文件浏览与视频按需读取、ZIPX / RAR / 7Z 等解压及包内预览继续保留。

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

要求 macOS 13 或更新版本；同一安装包支持 Apple Silicon 和 Intel。从 v1.2.0 起可在应用内检查更新。更新包与更新源使用既有 Ed25519 密钥签名；应用仍为 ad-hoc 签名，未经过 Apple 公证。

## English

LeafFiles 2.0.0 (build 13) focuses on **a refreshed interface and the rename from WinFile to LeafFiles**.

- Clearer tabs, toolbar and address bar; sidebar groups retain their collapsed state, and Storage Cleanup stays at the bottom.
- Cleanup pages highlight total and selected usage with distinct scan, filter and Move to Trash actions.
- Advanced search filters fold away with an active count. Archive previews adapt between side-by-side and stacked layouts, with collapsible details and a close control for the file preview.
- Larger local thumbnails, grouped file properties, a copy-folder action and a tighter icon grid.
- The LeafFiles name appears throughout both languages, menus, About, help and permission descriptions.
- Keep the original curl command, GitHub address, automatic update channel, favorites, tab sessions and settings. App and archive filenames retain `WinFile` for existing installations.

Requires macOS 13+. Universal Apple Silicon / Intel build. Existing WeChat cleanup, MTP Android browsing and on-demand video playback, multi-format extraction and archive previews remain available. Updates use the existing Ed25519 key; the app remains ad-hoc signed and is not Apple-notarized.
