# WinFile v1.3.1

版本 `1.3.1`，构建号 `6`。本次更新修复空间清理中的文件与应用来源识别，改善页签切换和详细信息栏入口。

## 修复与改进

- **百度网盘下载文件**：扫描常见的实际下载目录，支持手动指定并保存下载位置；在软件清理中可按下载文件、缓存与日志筛选。切换下载目录时清除旧扫描及勾选。
- **通用清理中的微信附件**：复用微信附件目录识别及用户添加的目录，优先扫描附件，避免大型缓存目录提前耗尽扫描限额。数据库及其他持久数据继续受保护。
- **应用来源显示**：来源筛选和文件列表统一显示应用名称；辅助组件优先归入已识别的主应用，无法解析的 bundle 标识归入「其他应用」。显示分组不改变实际扫描规则及清理前的占用保护。
- **页签切换**：保留公共工具栏及侧边栏，缓存最近 3 个页签的内容视图，切回时复用原生表格并保留滚动位置；关闭页签释放缓存，超出缓存的页签按需重建。
- **减少主线程开销**：合并活动模型的重复通知，读取当前页签不再触发刷新，诊断日志改为后台写入，正常使用不记录每次页签重绘。
- **菜单目标**：按当前原生窗口定位活动页签，避免缓存内容视图的焦点范围影响菜单操作及选中状态。
- **详细信息栏**：展开／收起按钮移至窗口顶部工具栏右侧。

扫描不会删除文件，清理仍需用户确认；本次更新不改变废纸篓及受保护数据规则。

## 验证

- `1.3.1 (6)` 通用应用包构建及代码签名验证通过。
- 使用 `--run-tests --skip-device-tests`，Apple Silicon 和 Intel/Rosetta 应用包分别 **987 项通过，0 项失败**；本轮不包含真实安卓设备读写。
- 真实窗口回归通过连续 12 次切换的原生表格复用、滚动位置保留、仅挂载活动页签、最多缓存 3 个页签、关闭后释放缓存，以及窗口菜单目标绑定。
- 本机界面确认选中状态同步到菜单，顶部详细信息栏按钮可正常收起和展开。

## English

WinFile 1.3.1 fixes storage cleanup detection and improves tab switching.

- Detect Baidu Netdisk downloads in common folders or a saved custom location.
- Include recognized WeChat attachments in General Cleanup while protecting databases and persistent data.
- Use consistent app names in source filters and rows; group identified helpers with their parent apps and unresolved identifiers under Other Apps.
- Reuse the three most recent tab content views, preserve scroll positions, coalesce refreshes and write diagnostics in the background.
- Resolve menu commands through the active tab of the current native window.
- Move the right inspector control to the top window toolbar.
- 987 tests pass in each Apple Silicon and Intel/Rosetta app bundle; physical Android device read/write tests are excluded. Native tab-cache, command-target and inspector-toggle checks pass.

Requires macOS 13 or later. Scanning does not delete files; cleanup still requires confirmation.
