# WinFile v1.2.1

这是一个针对微信文件清理的补丁版本，修复了切换排序时可能出现的界面卡死。

## 修复

- **微信清理切换排序不再卡死**：当附件数量较多（实测 8,700+ 项）时，点击表头切换排序偶发进入无限更新循环——CPU 占用 100%、界面完全无响应，只能强制退出。
  现已改为分页显示（每页 200 行），把一次表格重排的行数从 8,700+ 压到 200；排序状态合并为单次提交，一次点击只触发一次刷新；表格改用与其他文件列表一致的行标识方式。
- **排序语义保持不变**：排序仍作用于全部筛选结果，再按页显示；统计（总占用、筛选后数量）与「全选筛选结果」仍按全量计算；已选项在翻页后保留；切换排序或修改筛选条件会回到第 1 页。

## 验证

- 在 8,719 项真实微信附件上连续切换排序 **260 次**，未再出现卡死；每次操作后 CPU 均回落到常态。
- 自动化测试 **803 项通过**，Apple Silicon 与 Intel/Rosetta 双架构各自通过。

## 安装与升级

支持 macOS 13 及以上，安装包同时包含 Apple Silicon 和 Intel 架构。下载 `WinFile.zip`（或 `WinFile-1.2.1.zip`），解压后替换「应用程序」中的 WinFile；原有收藏、设置和文件保留。

已在 1.2.0 的用户可直接通过「WinFile → 检查更新」升级；**1.1.0 及更早版本仍需手动安装一次**，之后才能使用应用内更新。

也可退出 WinFile 后运行：

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

当前版本仍为 ad-hoc 签名，未进行 Apple 公证；首次打开请参阅 [README 安装说明](https://github.com/fakerUZI/macos_winfile#方式一下载安装包)。

## English

This is a patch release for WeChat cleanup, fixing an interface freeze when switching sort order.

- **Sorting no longer freezes the WeChat cleanup page**: with many attachments (8,700+ in testing), clicking a column header could occasionally enter an infinite update loop — 100% CPU, unresponsive UI, force quit required. Rows are now paginated (200 per page), so each table reorder applies to 200 rows instead of 8,700+; sort state is committed once per interaction; the table now uses the same row-identity approach as the other file lists.
- **Sorting semantics are unchanged**: sorting still applies to the whole filtered set before pagination; totals, filtered counts, and “Select All Filtered” still cover everything; selections survive page changes; changing sort or filters returns to page 1.

Verified with 260 consecutive sort changes on 8,719 real attachments without a freeze, and 803 automated tests passing on both Apple Silicon and Intel/Rosetta.
