# LeafFiles v2.1.0

版本 `2.1.0`，构建号 `18`。本次完善访达联动、语言切换与解压位置选择。

- **从访达打开压缩包**：右键支持的 ZIP / ZIPX / RAR / 7Z 等压缩包，在「打开方式」选择 LeafFiles，直接进入内置预览。注册为备用查看器，系统默认应用仍由你选择。
- **在 LeafFiles 中显示**：访达右键文件或文件夹，使用同名系统服务，在新页签定位并选中文件，或进入文件夹。支持多选，保留原有页签；冷启动也能接收请求。
- **菜单跟随中英文切换**：修复选择 English 后「设置、关于、隐藏、退出」仍显示中文的问题；菜单栏顶级标题同步更新，重复设置入口已去除。少数系统提供的窗口命令、输入法、听写及第三方服务文案仍可能采用系统语言。
- **解压位置可直接新建目录**：「解压到…」的内置选择器新增「新建文件夹…」，创建后自动进入新目录，再确认即可解压。支持连续新建多级目录，明确提示重名、无效名称与权限错误，原有目录和文件不会被覆盖。

## English

LeafFiles 2.1.0 (build 18) improves Finder integration, language switching and extraction destinations.

- **Open archives from Finder:** choose LeafFiles in Open With for supported ZIP, ZIPX, RAR, 7Z and other archives to open the built-in preview. LeafFiles registers as an alternate viewer; your default application remains your choice.
- **Show in LeafFiles:** use the Finder service to reveal files or browse folders in new tabs. Multiple selections and cold launches are supported, while existing tabs are preserved.
- **Localized application menus:** Settings, About, Hide and Quit now follow the selected English or Chinese language, alongside the top-level menu bar. The duplicate Settings entry is hidden. Some system-provided window commands, input methods, dictation and third-party services may retain the system language.
- **Create extraction destinations:** choose New Folder in the built-in Extract To picker. Successful creation opens the new folder, ready for confirmation. Nested folders can be created in sequence; conflicts, invalid names and permission errors are reported without overwriting existing items.

Thanks to [@KaKi87](https://github.com/KaKi87) for the [favorites and in-app picker suggestions #1](https://github.com/fakerUZI/macos_winfile/issues/1), [crash logs #2](https://github.com/fakerUZI/macos_winfile/issues/2) and [OrbStack report and follow-up #3](https://github.com/fakerUZI/macos_winfile/issues/3). These earlier reports were addressed in previous releases; the OrbStack recovery was confirmed by the reporter. This is an acknowledgment, not a claim of new OrbStack fixes in 2.1.0. The website now includes a dedicated community acknowledgments section.

The existing installation command, preferences, favorites and signed update channel remain compatible. Requires macOS 13+. Universal Apple Silicon / Intel build; ad-hoc signed, not Apple-notarized.
