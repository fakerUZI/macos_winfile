# LeafFiles v2.2.2

版本 2.2.2，构建号 21。

- 分类扫描覆盖已挂载的可见磁盘，为各范围分配扫描额度，优先逐步展示外接盘结果；连接或移除磁盘后自动刷新。扫描结果仍受深度、数量及文件访问权限限制。
- 新用户的个人收藏默认为空，不再自动加入六个标准目录；已有收藏保留，标准目录名称跟随语言显示。
- 页签支持拖动排序、右键移动、移到新窗口和合并窗口。重启后保存的页签恢复到一个窗口。
- 增强列表双击绑定的稳定性和诊断日志。感谢 @xuchen521 在 [Issue #4](https://github.com/fakerUZI/macos_winfile/issues/4) 中报告问题；本机未复现对方的问题，仍需要反馈者在自己的设备上验证。

已在隔离的 GitHub 2.2.1 发行包中测试双击文件和文件夹；用临时挂载磁盘映像验证外接盘分类及插拔刷新。ARM 和 Intel/Rosetta 回归各 1,343 项通过，跳过真实安卓设备读写。

## English

LeafFiles 2.2.2 (build 21) includes mounted volumes in category scans, displays results progressively, refreshes on connect and disconnect, and starts new installations with empty favorites while preserving existing ones. Tabs can be reordered, detached, and merged. Table double-click handling and diagnostics have also been improved. Thank you @xuchen521 for reporting [Issue #4](https://github.com/fakerUZI/macos_winfile/issues/4); confirmation on the reporter's machine is still needed.
