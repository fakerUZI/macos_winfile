# LeafFiles v2.0.2

版本 `2.0.2`，构建号 `15`。本次增加包内文件的默认应用打开，并统一常用菜单图标。

## 包内文件，交给熟悉的应用

- 在压缩包预览中，双击文件或点击「用默认应用打开」，即可打开文本、Markdown、图片、视频等文件。优先使用 LeafFiles 内指定的文件关联，未设置时使用 macOS 默认应用。
- 仅直接打开原始大小**小于 64 MiB** 的文件。达到限制、大小未知或链接会明确提示先解压，并提供内置解压位置选择器入口。
- 只临时解出所选文件，无须手动解压整个压缩包；单击仍仅选择，双击文件夹进入目录。
- 空格和「查看所选文件」继续使用内置 Quick Look，右上角「关闭」按钮保留。

## 临时文件与错误处理

- 外部应用使用独立的只读缓存，关闭压缩包窗口后仍可继续读取；同一预览会话重复打开会复用副本，修改不会写回原压缩包。
- 后续准备文件时，回收超过七天或超出 512 MiB 目标的旧会话缓存。本次 LeafFiles 运行中已交给外部应用的文件受保护，容量目标不是硬上限。
- 支持密码输入与重试、取消准备、源压缩包变化检查及默认应用启动失败提示。

## 更统一的菜单按钮

- 页签栏加号旁只保留一个下三角。
- 文件整理工具和详情栏更多操作仅显示省略号，去掉附加箭头；新建、复制为与紧凑显示菜单同步统一。
- 保留 macOS 原生配色，补充菜单无障碍名称。原 curl 安装命令、收藏、设置及自动更新渠道保持兼容。

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

要求 macOS 13 或更新版本，通用安装包支持 Apple Silicon 和 Intel。应用为 ad-hoc 签名，未经过 Apple 公证。自动更新下载文件仍使用 `WinFile-2.0.2.zip` / `WinFile.zip`。

## English

LeafFiles 2.0.2 (build 15) opens archive members in your preferred apps and simplifies menu icons.

- Double-click an archive member or choose **Open with default app** for text, Markdown, images, videos and other types. LeafFiles associations take priority, followed by the macOS default.
- Direct opening requires a known original size **smaller than 64 MiB**. Files at the limit, unknown sizes and links prompt you to extract first, with an in-app destination picker entry.
- Only the selected file is temporarily extracted. Single-click still selects; double-clicking a folder navigates into it. Space and **View selected file** retain embedded Quick Look; the original top-right Close button remains.
- External apps receive read-only cached copies that survive closing the archive window. Repeat opens in the same preview session reuse the copy; edits are not written back to the archive.
- Later file opens reclaim previous-session cache entries older than seven days or above a 512 MiB target. Files handed off during the current app run stay protected, so this is not a hard size cap.
- Password retries, cancellation, archive-change checks and application-launch errors are handled explicitly.
- One chevron beside the tab-bar plus, one ellipsis for More, no duplicate arrows in everyday menus, and clearer accessibility labels. Native colors, the existing curl command, settings and signed update channel remain compatible.

Requires macOS 13+. Universal Apple Silicon / Intel build; ad-hoc signed, not Apple-notarized.
