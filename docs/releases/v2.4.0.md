# LeafFiles v2.4.0

版本 2.4.0，构建号 26。

- 新增左右分屏，可选择已有标签页或新建标签页并排浏览；切换其他标签页后可回到原分屏。当前操作区域以边框标识，排序、升降序和视图切换作用于选中的一侧。
- 精简普通页面和搜索页面的操作栏，保留常用排序、视图与文件整理入口，文件操作可通过右键使用。
- 路径栏支持直接输入路径跳转与 Tab 补全；点击其他区域取消未提交的输入，改进符号链接目录读取。
- 分类页面的扫描范围可直接点击，打开当前类别的扫描设置。

分屏组合在退出应用后需要重新选择，已有标签页会保留。

## English

LeafFiles 2.4.0 (build 26) adds side-by-side browsing using an existing or new tab. The active pane is outlined, and sorting and view controls apply to that pane. The release also streamlines browser and search controls, improves direct path entry and symbolic-link handling, and adds direct access to each category’s scan settings. Tabs are retained on quit; split groups need to be selected again after restarting.
