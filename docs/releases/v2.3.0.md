# LeafFiles v2.3.0

版本 2.3.0，构建号 22。

- 分类页支持选择优先扫描目录，按需继续扫描其他位置；指定目录和其他位置共享结果与遍历上限，避免重复收集。此设置作用于当前页签。
- Dock 右键菜单增加新建窗口，也可通过「文件 → 新建窗口」或 ⌘N 打开独立窗口。
- 增加应用内常用文件快捷键、图标自由排列、侧栏开关状态记忆和剪切标记；移动成功后不再显示结果栏，失败和取消仍有提示。
- 改进 exFAT 等文件系统的磁盘容量读取：常规可用容量或文件系统统计作为回退，无法获取时不再误报 0 B。感谢 @skinnyshy 在 [Issue #5](https://github.com/fakerUZI/macos_winfile/issues/5) 提供问题和截图；本机尚无真实 exFAT 外置盘，请在原设备上验证。
- 感谢 @xuchen521 在 [Issue #4](https://github.com/fakerUZI/macos_winfile/issues/4) 反馈双击、外接盘扫描及收藏问题，并建议自定义扫描范围和记住详情栏状态。反馈者表示此前问题基本恢复；新功能欢迎继续验证。

真实拖动时的指针提示尚未通过自动化验证。个人文件、收藏和设置不会随更新删除。

## English

LeafFiles 2.3.0 (build 22) adds priority folders for category scans, independent windows from the Dock and ⌘N, file shortcuts, icon placement and pane visibility restoration. It improves exFAT volume capacity reporting. Thank you @skinnyshy for [Issue #5](https://github.com/fakerUZI/macos_winfile/issues/5) and @xuchen521 for [Issue #4](https://github.com/fakerUZI/macos_winfile/issues/4). The earlier issues were reported as mostly resolved; the new scan controls and exFAT fix welcome further verification on the reporters’ devices.
