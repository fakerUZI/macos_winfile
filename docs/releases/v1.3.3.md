# WinFile v1.3.3

版本 `1.3.3`，构建号 `8`。本次只调整界面：精简右上角工具栏，去掉重复的放大镜图标。**没有功能或数据变更**，升级后原有设置、收藏、页签与清理记录全部保留。

## 界面调整

- **右上角工具栏只保留两个按钮**：搜索与侧边栏（显示详细信息）。此前一排的「打开」「打开方式」「在访达中显示」已移除，避免图标拥挤与语义重复。
- **搜索图标统一为放大镜**：之前是「纸张 + 放大镜」，与「在访达中显示」的纯放大镜在小尺寸下难以区分；现在放大镜只代表搜索。

## 被移除按钮的替代入口

| 操作 | 现在从哪里进入 |
| --- | --- |
| 打开文件 | 双击文件；或右键 →「打开」 |
| 打开方式 | 右键文件 →「打开方式…」 |
| 在访达中显示 | 右键菜单；或右侧检查器中的同名按钮 |

## 验证

- Apple Silicon 与 Intel/Rosetta 通用应用包构建、代码签名校验通过。
- 自动化测试：命令行套件 **1032 项**、应用包内套件 **1037 项**，全部通过。
- 本机安装 1.3.3 后启动与浏览正常。

## 安装与升级

支持 macOS 13 及以上，安装包同时包含 Apple Silicon 和 Intel 架构。下载 `WinFile.zip`（或 `WinFile-1.3.3.zip`），解压后替换「应用程序」中的 WinFile。

已在 1.2.0 及更高版本的用户可直接通过「WinFile → 检查更新」升级；**1.1.0 及更早版本仍需手动安装一次**。

也可退出 WinFile 后运行：

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

当前版本仍为 ad-hoc 签名，未进行 Apple 公证；首次打开请参阅 [README 安装说明](https://github.com/fakerUZI/macos_winfile#方式一下载安装包)。

## English

WinFile 1.3.3 (build 8) is a UI-only update: the top-right toolbar is trimmed and the duplicate magnifier icon is gone. **No functional or data changes**; existing settings, favorites, tabs and cleanup history are preserved.

- The top-right toolbar now keeps only **Search** and **Sidebar** (show details). The “Open”, “Open With” and “Reveal in Finder” buttons were removed to reduce icon crowding and overlapping meaning.
- The search icon is now a plain magnifier. It previously used document-plus-magnifier, which was hard to tell apart from “Reveal in Finder” at toolbar size; the magnifier now means search only.

Removed buttons remain available elsewhere: double-click a file to open it, right-click for Open and Open With, and use the context menu or the inspector for Reveal in Finder.

Builds for Apple Silicon and Intel/Rosetta pass code-signature verification; the command-line suite passes 1032 tests and the app-bundle suite passes 1037. Requires macOS 13 or later; users on 1.2.0 or later can update in-app, while 1.1.0 and earlier still need one manual install.
