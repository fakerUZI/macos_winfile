# LeafFiles v2.2.1

版本 `2.2.1`，构建号 `20`。本次修复文件拖放时可能意外创建副本的问题。

- **当前目录内移动**：将当前目录的文件或文件夹拖入子文件夹时移动原项目，不再复制一份；拖到当前目录空白处不会创建副本。
- **其他目录拖入仍为复制**：从其他目录拖入文件或文件夹时保留源项目；需要在当前目录创建副本时，可使用复制与粘贴。
- **保留操作保护**：读取拖入项目失败，或一次拖入混合来源的项目时会提示；移动沿用现有传输进度和撤销机制。

图标视图中的实际目录移动已用隔离测试目录验证，原位置没有留下副本。列表与图标视图共用相同的拖放策略。

使用原有终端安装命令，或在应用内检查更新。支持 macOS 13 及以上的 Apple Silicon 和 Intel Mac；安装包为 ad-hoc 签名，未经过 Apple 公证。

## English

LeafFiles 2.2.1 (build 20) fixes unexpected copies during drag and drop.

- Items dragged from the current folder into a subfolder are moved; dropping them on the current folder's empty area no longer creates duplicates.
- Items dragged in from other folders are copied, preserving the originals. Use copy and paste to explicitly make a copy in the current folder.
- Unreadable items and mixed sources prompt a retry or separate drops; move progress and undo remain available.

An isolated icon-view test confirmed the moved folder no longer remains at its original location. Details and icon views share the same drop policy.

Use the existing terminal installer or Check for Updates. Requires macOS 13+; universal Apple Silicon and Intel build; ad-hoc signed, not Apple-notarized.
