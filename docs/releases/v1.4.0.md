# WinFile v1.4.0

版本 `1.4.0`，构建号 `10`。本次将安卓文件管理统一迁移到 MTP，并加入按需读取的内置视频播放，减少打开视频产生的整文件磁盘写入。

## 安卓文件管理

- USB 选择「文件传输」即可，应用内置双架构 libmtp / libusb 和辅助进程，不再使用 ADB，无需开启 USB 调试或安装 Homebrew。
- 支持浏览实际存储位置、新建、上传、下载、复制、重命名及删除。设备内移动取决于手机能力，不支持时明确提示，不自动删除原文件；复制仍需本机临时空间。MTP 删除是永久删除，操作前确认。
- 插入、拔出、解锁后的就绪状态和重连自动更新，无需重启。修复设备临时身份转为真实序列号、USB 地址变化及上级目录尾部斜杠导致的读取失败。
- 保持页签与原设备绑定，不把旧设备操作转发给新设备。只在只读目录请求中对同一设备重连重试一次，不自动重放写入或传输。
- 修复关闭 MTP 会话引发 USB 重置、导致后续请求暂时失败的问题。传输支持取消与超时终止，辅助进程不阻塞主窗口。

## 视频按需播放

- 安卓视频双击或右键「打开」使用内置播放器，空格先暂停预览，支持拖动进度；一次打开一个视频。
- 通过 MTP 分段读取播放器需要的范围，使用共享 **32 MiB** LRU 视频数据缓存；不创建完整视频磁盘副本。关闭播放器、断连或换设备时取消读取并释放自身缓存。
- 32 MiB 是共享视频数据缓存上限，不是播放器解码帧或应用总内存上限，也不代表系统交换内存和诊断日志完全不写盘。
- 编码支持取决于 macOS AVFoundation，设备也需支持对应的分段读取。不兼容时明确报错，不自动完整下载；外部播放器请手动下载后使用。
- 其它文件仍使用经校验的只读本机副本，由默认应用或 Quick Look 打开，不自动回写手机。缓存目标为 2 GiB / 7 天，在准备文件时清理；当前会话已打开的副本受保护，可能超过目标。手动下载到用户目录的文件不会自动删除。

## 诊断与维护

- 诊断日志增加完整时间戳、2 MiB 轮转和三份历史记录，方便定位偶发断连；测试日志与日常应用日志隔离。
- 清除旧 ADB 实现与生产目录中的测试探针，补充 MTP 协议、设备身份和视频范围读取回归，以及模块格式规范。
- 保留微信与其它软件清理、RAR / 7Z 解压、内置搜索、多页签、收藏拖放和中英切换等现有功能。

## 验证与限制

- 逻辑回归 1,149 项通过；连接联想小新平板 Pro GT 的完整回归 1,179 项通过；包含真实 MTP 视频播放的应用包回归 **1,184 项通过，0 失败**。
- 版本号更新后的最终发行包：arm64 与 x86_64/Rosetta 各 **1,154 项通过，0 失败**（跳过真实设备读写）；更新包签名与篡改拒绝 4 项、隔离安装与失败回滚 6 项均通过。
- 独立 helper 协议复测 53 项通过。首轮上传取消测试出现一次设备超时，清理测试目录并补强测试进程终止后复测通过，详见 [验收记录](https://github.com/fakerUZI/macos_winfile/blob/main/docs/qa/2026-10-22-mtp-streaming.md)。
- 真界面验证播放、跳到第 8 秒、空格暂停预览及不兼容视频提示。67,354,877 字节生成视频按需读取 2,343,165 字节，包含尾部索引跳读，磁盘视频缓存前后未变化；该样例含填充块，不代表高码率性能基准。
- 未物理覆盖所有设备品牌或实际超过 4 GiB 的文件；大偏移由虚拟 6 GiB 模型测试覆盖。手机只暴露其 MTP 允许访问的内容，应用私有数据可能不可见。
- macOS 13+，通用包支持 Apple Silicon 和 Intel；v1.2.0 及以上支持应用内更新，更早版本需手动升级一次。
- 当前应用使用 ad-hoc 签名，未进行 Apple 公证。更新包和更新源均由既有 Ed25519 密钥签名验证。

## English

WinFile 1.4.0 (build 10) moves Android file management to MTP and adds on-demand video playback from memory.

- Select USB File Transfer; bundled universal libmtp / libusb replace ADB. USB debugging and package managers are unnecessary. Browse, create, upload, download, copy, rename and delete files; native moves depend on device support. Copy operations still need temporary local disk space; device deletion is permanent and requires confirmation.
- Device insertion, removal, readiness and reconnection refresh automatically. Fix temporary-to-real identity changes, stale USB addresses, parent-directory navigation and USB resets when closing sessions. Tabs stay bound to the original device; writes and transfers are never automatically replayed.
- Double-click a video for the built-in player, or press Space for a paused preview. Seeking reads only required MTP ranges into a shared **32 MiB video-data cache**, without a full video disk copy. Closing or disconnecting cancels reads and releases the cache. This is a cache limit, not a limit on total process memory or a promise of zero operating-system writes.
- Unsupported device reads or macOS AVFoundation codecs report an error without downloading automatically. Use Download explicitly for external players. Other documents still use verified read-only local copies, with a 2 GiB / seven-day cleanup target and protection for copies opened in the current session; edits are not uploaded automatically. Manual downloads are retained.
- Timestamped diagnostics rotate at 2 MiB with three historical logs. Remove legacy ADB code, isolate test probes, and expand MTP, identity and byte-range regression coverage.

Validation: 1,149 logic checks; 1,179 connected-device checks; **1,184 app-bundle checks including physical-device video playback**, all passed. The independent helper protocol suite passed 53 checks on retry after an upload-cancellation timeout. Playback, seeking, paused previews and unsupported-video feedback were verified in the real UI. A generated 67 MB video required about 2.34 MB of reads, including its tail index, with unchanged disk-cache contents. This padded sample validates range access, not high-bitrate throughput. Physical files over 4 GiB and all device brands were not tested.

Final versioned release bundles passed **1,154 checks each on arm64 and x86_64/Rosetta** with physical-device tests excluded. Four signature/tamper-rejection checks and six isolated installation/rollback scenarios passed.

Requires macOS 13+. Universal Apple Silicon / Intel build; in-app updates available from v1.2.0. The app is ad-hoc signed and not Apple-notarized. Existing Ed25519 signatures verify update archives and feeds.
