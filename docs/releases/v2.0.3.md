# LeafFiles v2.0.3

版本 `2.0.3`，构建号 `16`。本次让新建 ZIP 更适合分享：自动过滤 macOS 杂项，保留其他隐藏文件。

## 压缩时过滤 macOS 杂项

- 新建 ZIP 自动排除各层级的 `.DS_Store`、`._*` 和 `__MACOSX` 目录及其内容；普通文件夹、直接多选与跨目录合并压缩均生效。
- 保留 `.git`、`.env`、`.gitignore`、`.config`、`.localized` 等其他隐藏项、空目录和符号链接本身。`.DS_Store.backup`、`report._draft.txt`、`__MACOSX_notes` 等相似名称也会保留。
- 只过滤打包内容，不删除或修改源文件，不改动已有压缩包。
- 只选中杂项时，明确提示没有可压缩的内容，不生成空包；完善横线开头文件名的处理。

包内默认应用打开、空格快速预览、微信附件整理、MTP 安卓文件管理等功能继续保留。

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

原 curl 命令、收藏、设置与签名更新渠道保持兼容。需要 macOS 13 或更新版本；通用安装包支持 Apple Silicon 与 Intel。应用为 ad-hoc 签名，未经过 Apple 公证。发行文件继续使用 `WinFile-2.0.3.zip` / `WinFile.zip`。

## English

LeafFiles 2.0.3 (build 16) creates ZIP archives without macOS metadata clutter while retaining other hidden files.

- Exclude `.DS_Store`, `._*` and `__MACOSX` directories and their contents at every level. This applies to folders, direct multi-selection and combined selections from different directories.
- Keep `.git`, `.env`, `.gitignore`, `.config`, `.localized`, other hidden items, empty folders and symlinks. Similar names such as `.DS_Store.backup`, `report._draft.txt` and `__MACOSX_notes` remain intact.
- Filter only archive contents; source files and existing archives remain untouched.
- Selecting only metadata shows a clear message instead of creating an empty archive. Filenames beginning with a dash are handled safely.
- Default-app opening of archive members, Space for Quick Look, WeChat cleanup and MTP Android features remain available.

The existing curl command, preferences and signed update channel remain compatible. Requires macOS 13+. Universal Apple Silicon / Intel build; ad-hoc signed, not Apple-notarized.
