# WinFile v1.3.2

版本 `1.3.2`，构建号 `7`。新增 WinFile 原生搜索弹窗，修复符号链接导航与会话恢复，并补充文件错误诊断信息。本次稳定发行同时包含此前已提交的清理识别和页签性能改进。

## 原生搜索

- `⌘F`、顶部搜索按钮、文件夹搜索旁的筛选按钮及「文件整理工具 → 组合搜索」统一进入 WinFile 搜索弹窗，不调用访达搜索。
- 在应用内选择搜索范围，支持名称、文件或文件夹、分类、扩展名、大小和修改日期的组合条件；可切换子文件夹及隐藏文件。
- 显示扫描数量，支持停止搜索和扩大达到上限的扫描；取消后可保留已找到的结果，不把部分扫描表示为完整结果。
- 搜索结果支持排序、双击打开、复制路径，以及在新页签打开所在文件夹并定位结果；搜索弹窗不会改变原页签的搜索状态。
- 只搜索文件名及元数据，不读取文件内容；跳过扫描过程中遇到的子符号链接和应用包内部，避免循环和越出范围。

## 符号链接修复

- 目录链接和同级真实目录不再共用列表 ID，分别保留自己的名称和选择状态。
- 有效目录链接在 WinFile 内打开；地址栏直接进入链接、应用内目录选择、显式链接搜索范围及旧会话恢复均可解析目标路径。
- 目录监听与保存的页签使用实际目标目录，避免有效链接导致目录枚举错误及下次启动重复报错。
- 失效或循环链接在打开时显示明确提示，父目录其他项目仍可浏览。
- 复制和重命名以链接本身为对象；旧复制入口不再将复制目录链接误判为递归复制目标目录。

本机 macOS 15.8.1 上的符号链接问题已有修复前失败、修复后成功的对照。使用真实 OrbStack NFS 挂载，运行和停止状态下共执行 40 次启动、开关页签及地址栏提交检查，未观察到原帖所述重复弹窗。**macOS 26 上的原始 OrbStack 故障尚未独立复现，仍需报告者验证，本版本不声称已解决该故障。**

## 诊断日志

- 启动日志包含应用版本、构建号及系统版本。
- 目录枚举与链接打开解析失败时记录操作、路径、NSError 的 domain/code 及底层错误链，不导出任意 userInfo 或文件内容。
- 日志错误链限制为最多 8 层，换行转义为文字，继续由后台队列落盘。
- 复现后关闭错误弹窗，选择「帮助 → 在访达中显示日志」，复制 `~/.winfile-mac/tab-diagnostics.log`。启动会重置日志，**再次启动前请先复制**；分享前检查并遮盖私人路径。

## 同时包含的清理与页签改进

- 百度网盘实际下载目录识别及手动位置保存。
- 通用清理中的微信附件识别和持久数据保护。
- 应用来源使用可读名称，辅助组件归入可识别的主应用。
- 最近三个页签内容视图复用、滚动位置保留、刷新合并、活动窗口菜单绑定，以及顶部工具栏的详细信息按钮。

## 验证

- Apple Silicon 和 Intel/Rosetta 通用应用包构建及代码签名验证。
- 使用 `--run-tests --skip-device-tests` 验证两种架构；本轮不包含真实安卓设备读写。
- 覆盖原生搜索、符号链接及错误诊断回归；并验证真实窗口页签切换。
- 发布前校验 Ed25519 更新包及更新源签名、篡改拒绝和一键安装流程。

## English

WinFile 1.3.2 (build 7) adds a dedicated native search sheet, fixes symbolic link browsing and session restoration, and improves filesystem error diagnostics.

- Search inside WinFile with an in-app scope picker and combined name, entry kind, category, extension, size and modification date filters. Stop or expand limited scans, sort results, open matches or locate them in a new tab. File contents are not searched.
- Directory links open inside WinFile and retain separate list identities from their targets. Address-bar navigation, folder picking, explicit search roots and saved linked tabs resolve correctly. Unavailable links report an error; copying and renaming still act on the link itself.
- Diagnostics include app/build/macOS versions and bounded NSError domain/code/underlying-error chains for directory listing and link resolution. After reproducing an issue, use **Help → Reveal Diagnostics Log** and save a copy before restarting. Review personal paths before sharing.
- Also includes Baidu Netdisk and WeChat cleanup detection fixes, readable app sources, cached tab content and the top-toolbar inspector control.

The symbolic link regressions are verified locally. Real OrbStack NFS checks pass on macOS 15.8.1, but **the original macOS 26 OrbStack issue remains unconfirmed and is not claimed as resolved**.

Requires macOS 13 or later. Physical Android device read/write tests are excluded from this release’s validation.
