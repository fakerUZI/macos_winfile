# LeafFiles v2.0.1

版本 `2.0.1`，构建号 `14`。本次完善压缩包预览和常用页面交互，并统一访达中的应用名称。

## 感谢反馈与修复确认

感谢 [@KaKi87](https://github.com/KaKi87) 提供问题反馈、复现信息和后续验证。

- **OrbStack 目录打开已恢复**：此前反馈的 “The file `OrbStack` couldn't be opened” 问题，已在先前版本中修复相关目录与符号链接处理；报告者于 2026-10-23 在 [issue #3](https://github.com/fakerUZI/macos_winfile/issues/3) 回复确认问题看起来已修复。此处记录反馈确认，并非声称本版本新增了另一项 OrbStack 修复。
- 同时感谢他在 [issue #2](https://github.com/fakerUZI/macos_winfile/issues/2) 提交应用切换时崩溃的日志，以及在 [issue #1](https://github.com/fakerUZI/macos_winfile/issues/1) 提出直接添加文件夹到收藏和使用内置选择器的建议；这些修复和功能已随此前版本提供。

## 压缩包预览

- 支持按目录逐层浏览、返回上级和面包屑导航，正确合并隐含目录并显示空目录。
- 搜索覆盖整个压缩包，结果显示完整路径；列表突出名称、大小与类型，压缩及加密信息收纳到详情中。
- 单击选中，双击文件或按空格才准备预览；切换选中项保留当前预览，减少重复读取和临时文件写入。
- 预览区统一展示加载、密码及错误状态，支持收起；“解压全部”明确作用范围。

## 常用页面与交互

- 保留 macOS 原生配色，优化按钮图标、悬停反馈、禁用状态及紧凑窗口的布局。
- 文件详情分组更清晰，常用操作固定展示；安卓文件可在新页签定位到设备内的所在目录。
- 搜索条件可逐项移除；清理页完善空结果重置和底部已选数量、占用统计。
- 安卓文件标识包含设备身份，避免不同设备相同路径的条目冲突。

## 应用名称与升级

- 安装目录统一为 **LeafFiles.app**，访达中显示新名称。安装脚本自动备份并迁移旧的 `WinFile.app`，失败时回滚。
- 原 curl 命令、应用标识、收藏、页签、设置和自动更新签名密钥继续沿用；下载文件仍为 `WinFile.zip` / `WinFile-2.0.1.zip`。
- 应用内更新可能沿用原安装目录；若更新后访达仍显示 `WinFile.app`，退出应用后运行下方安装命令即可迁移。

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

要求 macOS 13 或更新版本；通用安装包支持 Apple Silicon 和 Intel。应用仍为 ad-hoc 签名，未经过 Apple 公证。

## English

LeafFiles 2.0.1 (build 14) improves archive browsing, everyday controls and the app’s name in Finder.

**Thanks to [@KaKi87](https://github.com/KaKi87)** for reporting bugs and following up. The OrbStack folder-opening problem was addressed by earlier directory/symlink fixes, and the reporter confirmed that it seems fixed on October 23 in [issue #3](https://github.com/fakerUZI/macos_winfile/issues/3). This release records that confirmation, rather than claiming a new OrbStack-specific fix. Thanks also for the crash logs in [issue #2](https://github.com/fakerUZI/macos_winfile/issues/2) and the favorites / in-app picker suggestions in [issue #1](https://github.com/fakerUZI/macos_winfile/issues/1), addressed in earlier releases.

- Browse archives by folder with breadcrumbs and Up navigation, including inferred and empty directories. Search across the archive with full paths.
- Select rows without extracting; double-click a file or press Space to prepare its preview. Keep the current preview while changing selection to reduce repeated reads and temporary writes.
- Clearer preview loading, password and error states, collapsible details, and an explicit Extract All action.
- Retain native macOS colors with clearer toolbar icons, hover/disabled feedback, compact layouts, grouped file details, removable search filters and cleanup selection totals.
- Locate Android files in a new device-folder tab; include device identity in file IDs to prevent cross-device collisions.
- Install as **LeafFiles.app**. The curl installer backs up and migrates legacy WinFile.app installations and rolls back on failure. Existing settings and update signatures remain compatible; download filenames stay unchanged. In-app updates may retain the old directory name; quit and rerun the curl installer to migrate it.

Requires macOS 13+. Universal Apple Silicon / Intel build; ad-hoc signed, not Apple-notarized.
