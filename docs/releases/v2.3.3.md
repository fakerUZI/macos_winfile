# LeafFiles v2.3.3

版本 2.3.3，构建号 25。

- 改进图标视图中的文件夹拖放：拖入目标文件夹时显示移动提示，在空白处放下可自由排列图标。
- 手动更改排序方式或方向时，清除当前文件夹的自定义图标位置，恢复按所选规则排列。
- 拖动预览保留文件名，改善目标判定及松开后的显示。

## English

LeafFiles 2.3.3 (build 25) improves folder dragging in icon view. A move indicator appears over a destination folder, while dropping on empty space arranges icons freely. Choosing a sort order resets custom positions in the current folder. Drag previews retain the file name and improve destination detection and the display after release.
