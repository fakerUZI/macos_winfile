# LeafFiles v2.2.0

版本 `2.2.0`，构建号 `19`。本次围绕日常文件浏览，优化图标配色与左右侧栏交互。

- **侧栏与主页图标配色**：恢复侧栏的蓝色导航图标和文件分类色；主页快速访问同步使用蓝色常用目录、绿色图片、橙色影片与紫色音乐图标，文字和卡片保留原有层次。
- **左右侧栏原位收起与展开**：分隔线更清晰，中间增加方向箭头。收起后在窗口边缘保留反向箭头，点击即可展开并恢复之前的宽度；两侧可分别操作，也可同时收起。
- **保留宽度调整习惯**：仍可拖动分隔线调宽、双击恢复默认宽度；顶部展开按钮继续可用。收起后的边条单独占位，不覆盖文件或滚动条。空间清理页面不显示不适用的右侧展开入口。
- **修复文件夹图标闪现**：网格和列表在异步读取真实图标前，直接显示 macOS 系统文件夹图标，消除切换目录时黄色占位图一闪而过的问题；自定义图标仍继续加载。

感谢此前通过 GitHub Issues 提供建议、复现信息和修复验证的 [@KaKi87](https://github.com/KaKi87)，以及持续反馈界面体验的用户。社区致谢与相关历史反馈继续保留在官网致谢区。

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

现有用户也可使用应用内「检查更新」。原安装命令、个人设置、收藏和 Sparkle 签名更新渠道继续兼容。需要 macOS 13 或更新版本，通用安装包支持 Apple Silicon 与 Intel。应用为 ad-hoc 签名，未经过 Apple 公证；发行文件沿用 `WinFile-2.2.0.zip` / `WinFile.zip`。

## English

LeafFiles 2.2.0 (build 19) refines icon colors and pane controls for everyday file browsing.

- **Sidebar and Home colors:** blue navigation icons and file-category colors return to the sidebar. Quick Access uses blue for common locations, green for Pictures, orange for Movies and purple for Music, retaining the existing text and card styling.
- **Collapse and reopen in place:** clearer dividers include directional arrow buttons. Collapsed panes retain reverse arrows at the window edges; click to reopen at the previous width. Both panes can be collapsed independently or together.
- **Keep familiar width controls:** drag dividers to resize, double-click to reset, or reopen panes from the toolbar. Collapsed rails reserve their own space without covering files or scrollbars. Cleanup pages omit the unavailable inspector control.
- **Fix folder-icon flashes:** lists and grids show the macOS folder icon immediately while the real icon loads, removing the brief yellow placeholder during folder changes. Custom icons still load asynchronously.

Thanks to [@KaKi87](https://github.com/KaKi87) for earlier GitHub suggestions, reports and follow-up checks, and to users sharing interface feedback. Community acknowledgments and related earlier reports remain available on the website.

Use the existing installation command or Check for Updates in the app. Preferences, favorites and the signed update channel remain compatible. Requires macOS 13+; universal Apple Silicon / Intel build; ad-hoc signed, not Apple-notarized.
