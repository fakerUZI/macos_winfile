# WinFile 1.1.0

macOS 13+，支持 Apple Silicon / Intel。

## 三项重点更新

- 微信文件清理：发现本机附件，按名称、类型、大小、时间、账号、月份及来源筛选；显示全部 / 当前筛选 / 已选占用，支持类型与月份分布。双击打开、空格预览，打开所在目录会激活新页签。清理需确认并移到废纸篓，跳过聊天数据库。
- 安卓文件查看：通过 USB + adb 浏览已授权设备的公共存储目录，支持上传、下载、新建、重命名、复制、移动及删除。需自行安装 Android Platform Tools 并授权 USB 调试；安卓删除为永久删除。
- 解压：内置官方 7-Zip，支持 ZIP / RAR（含 RAR5）/ 7Z / TAR、GZip / BZip2 / XZ 及 TAR 组合格式；密码重试、分卷归并、批量解压、取消及独立输出目录。同名保留两者，先验证并在私有暂存区域内完成解压。

## 其它改进

跟随系统或手动选择中英文；页签溢出、固定及恢复关闭；每页签独立显示状态与会话恢复；复制字节进度、取消、失败重试和新页签查看结果；批量重命名预览与撤销、大小/日期组合搜索、按完整内容查找重复文件；可调面板和记忆列宽。

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

安装前退出 WinFile。脚本验证 SHA-256 和应用包签名，保留旧版本备份。也可下载 `WinFile.zip` 后拖入「应用程序」。当前发行版为 ad-hoc 签名，尚未公证。

## 验证与范围

命令行 675 项、应用包 680 项及页签冒烟测试通过。一键安装另以临时目录做集成验证，不替换用户应用。

微信扫描只读取本机文件系统，不解密聊天数据库、不按联系人分组；未下载到 Mac 的附件不会出现。配图使用示例附件；重复文件工具不会自动删除文件。
