# LeafFiles v2.0.4

版本 `2.0.4`，构建号 `17`。本次集中改善文件浏览的流畅度与显示完整性。

- **大量文件滚动更流畅**：原生滚动容器复用可见行与磁贴，缓存系统文件图标和默认应用查询结果，减少重复布局。
- **修复悬停残影**：鼠标停留在文件区时，滚动会重新定位悬停目标，及时清除旧磁贴的底色。
- **扫描提示不再遮挡文件**：「继续加载 / 深入扫描」、任务提示和底部状态栏各自占位，首个图标与最后一行文件保持可见；提示消失后自动归还空间。图标与详细列表均适用。

近期修复已完成回归验证，当前本机使用中暂未发现明显问题。LeafFiles 会继续专注文件浏览、整理和管理，后续以界面优化、性能提升和问题修复为主，不扩展无关功能。欢迎继续反馈使用中遇到的问题。

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

原安装命令、个人设置、收藏及签名更新渠道保持兼容。需要 macOS 13 或更新版本；通用安装包支持 Apple Silicon 与 Intel。应用为 ad-hoc 签名，未经过 Apple 公证。发行文件继续沿用 `WinFile-2.0.4.zip` / `WinFile.zip`。

## English

LeafFiles 2.0.4 (build 17) improves the smoothness and clarity of everyday file browsing.

- Reuse native grid rows and tiles, with cached system icons and default-app lookups, to reduce layout work when scrolling through many files.
- Fix stale hover backgrounds when scrolling under a stationary pointer.
- Give scan notices, task banners and the bottom status bar their own layout space so they no longer cover file icons or rows. Both icon and detail views reclaim the space when a notice disappears.

The recent fixes have passed regression checks, with no obvious issues found in local use. LeafFiles remains focused on file management. Future work will prioritize interface improvements, performance and bug fixes, without expanding into unrelated tools.

The existing installation command, preferences, favorites and signed update channel remain compatible. Requires macOS 13+. Universal Apple Silicon / Intel build; ad-hoc signed, not Apple-notarized.
