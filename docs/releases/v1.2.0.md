# WinFile v1.2.0

本次更新完善个人收藏管理，增加应用内自动更新，并修复切换应用时可能出现的崩溃。

## 新增与修复

- **拖动添加个人收藏**：从 WinFile 列表、图标视图或访达拖入本地文件夹即可添加侧边栏快捷入口，不复制或移动源目录。支持去重，拒绝普通文件、应用包和失效目录。
- **应用内文件夹选择器**：侧边栏、收藏右键菜单、管理面板及设置中的添加入口统一使用 WinFile 自带弹窗，支持双击浏览、输入路径、隐藏目录、筛选与同级多选。
- **右键快捷收藏**：直接添加选中的文件夹或当前目录，保留当前页签和浏览位置；收藏重启后保留，可排序和移除。
- **原生自动更新**：每次启动检查 GitHub 稳定版，提供安装更新、跳过此版本和稍后提醒；也可手动检查或关闭启动检查。更新源和安装包均校验 Ed25519 签名，有文件任务时等待完成后再重启。
- **崩溃修复**：修复切换应用、双击文件打开外部应用时，异常鼠标坐标可能导致的崩溃，并清理失效窗口的事件监听器。

## 安装与升级

支持 macOS 13 及以上，安装包同时包含 Apple Silicon 和 Intel 架构。下载 `WinFile.zip`（或 `WinFile-1.2.0.zip`），解压后替换「应用程序」中的 WinFile；原有收藏、设置和文件保留。

也可退出 WinFile 后运行：

```bash
curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
```

**v1.1.0 及以前的用户需手动升级到本版本一次，之后才能使用应用内更新。** 当前版本仍为 ad-hoc 签名，未进行 Apple 公证；首次打开请参阅 [README 安装说明](https://github.com/fakerUZI/macos_winfile#方式一下载安装包)。

## English

- Add sidebar favorites by dragging local folders from WinFile’s detail list, icon view, or Finder. This creates shortcuts and keeps the original folders in place.
- All sidebar Add Folder actions now use WinFile’s own folder picker, with path entry, double-click navigation, hidden folders, filtering, and multiple sibling selection.
- Add selected folders or the current directory from the context menu, without changing the browsing tab. Favorites persist across restarts.
- Native launch-time update checks with Install Update, Skip This Version, and Remind Me Later. Signed feeds and packages are verified; active file operations finish before installation and relaunch.
- Fix crashes when switching apps or opening a file in another app, caused by invalid mouse coordinates and stale event monitors.

**Users on v1.1.0 or earlier must upgrade manually once to enable future in-app updates.** Requires macOS 13 or later; universal Apple Silicon / Intel app. This release is ad-hoc signed and not Apple-notarized; see the [installation instructions](https://github.com/fakerUZI/macos_winfile/blob/main/README.en.md#option-1-download-the-release).

## 验证 / Validation

- 命令行 771 项通过；arm64 与 x86_64/Rosetta 应用包各 776 项通过。跳过安卓实机文件操作。
- 完成独立测试应用的签名更新、安装、重启，以及跳过版本和稍后提醒验证。
- 发行文件通过四项签名回归测试，包括篡改安装包与更新源的拒绝检查。
- 实测应用内目录选择器；手动拖动添加收藏成功，并确认普通文件被拒绝。

维护者参阅[自动更新与发布流程](https://github.com/fakerUZI/macos_winfile/blob/main/docs/automatic-updates.md)。
