# WinFile v1.4.1

版本 `1.4.1`，构建号 `11`。修复安卓图片打开后，即使关闭图片窗口，设备仍可能变成“等待文件传输就绪”或目录显示“已断开”的问题。

## 安卓图片与 PDF 打开

- 图片和 PDF 的双击、右键打开默认使用 WinFile 已有的 Quick Look 面板，避免自动启动 macOS「预览」及相机导入进程后独占 MTP 的 USB 接口。空格预览保持一致，多张图片可在同一面板切换。
- 图片与普通文档混合选择时，分别交给内置预览和外部默认应用。普通文档默认打开、本地文件关联和安卓视频的 MTP 内存播放保持原有行为。
- 非视频文件仍需经校验的本机只读缓存，不会将修改回传到安卓。缓存可以复用，保留现有 2 GiB / 七天按需清理与会话保护规则；要用外部应用打开或编辑图片/PDF，请手动下载。

## 设备占用与恢复

- 同一 USB 连接暂时无法建立 MTP 会话时，保留此前识别到的设备名称和身份用于展示，同时清除就绪状态与可访问存储，避免设备名称突然变成 USB 编号。
- 设备页状态随连接变化更新，不再一直显示“正在读取设备存储”。占用提示明确说明「预览」「照片」「图像捕捉」等应用可能占用设备，以及“关闭窗口”不等于“退出应用”。释放占用后自动恢复。
- 保留设备隔离：断开后不继承旧身份，识别到另一台设备也不重定向旧页签，不增加写操作自动重试，不绕过序列号校验。
- 用户主动启动外部相机导入应用时，仍可能发生 USB 独占。本次修复不强制退出用户应用、不终止系统相机进程，也不修改系统 USB 设置。

## English

WinFile 1.4.1 (build 11) fixes Android device access becoming unavailable after opening and closing an image.

- Android images and PDFs now open in WinFile’s Quick Look panel by default. This avoids automatically launching Preview and its camera importer, which can exclusively claim the USB interface used by MTP. Space previews and browsing multiple images in one panel remain available.
- Mixed selections route pictures/PDFs to Quick Look and other documents to their default apps. Local file associations and memory-based MTP video playback are unchanged. Non-video files still use verified, reusable read-only local copies and the existing 2 GiB / seven-day cleanup target with current-session protection. Download explicitly for external image/PDF apps; edits are not uploaded automatically.
- Keep the known device name while the same USB attachment is temporarily unavailable, but clear readiness and storage. Replace the persistent “Reading device storage” status with the actual connection state. Explain that closing a Preview, Photos or Image Capture window may not release USB access; quitting the app can do so, after which WinFile recovers automatically.
- Identity stays isolated across disconnects and device changes. No automatic replay of writes or bypass of serial checks. Explicitly opening an external camera-import app can still claim USB; WinFile does not terminate user apps or system camera processes or change USB settings.

Feature validation before the version bump, using the same fix: 1,162 logic checks; 1,191 arm64 app-bundle checks with a physical Lenovo tablet; 1,167 Intel/Rosetta checks excluding physical-device operations, all passing. Real-window tests covered repeated image opens/closes, PDF viewing and directory refresh, without MTP or directory-read errors in the fixed session. Personal photos were not reopened.

Final 1.4.1 (11) release builds passed **1,167 checks each on arm64 and x86_64/Rosetta**, with physical-device operations excluded. Four signature/tamper-rejection checks and six isolated installation/rollback scenarios passed.

Requires macOS 13+. Universal Apple Silicon / Intel build; in-app updates available from v1.2.0. The app is ad-hoc signed and not Apple-notarized. Existing Ed25519 signatures verify update archives and feeds.
