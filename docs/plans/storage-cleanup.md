# 通用空间清理实施与验收

在 main 分支以 Swift 独立实现，参考 Mole 的规则、预览、保护与有界扫描机制，不引入其源码或执行其清理脚本。

1. 新增“空间清理”：常见应用缓存、日志、安装包、大文件，以及扫描目录的空间分布。保留微信附件入口。
2. 清理使用明确规则：缓存与日志按应用归属分类；保护数据库、凭据、持久数据和符号链接；扫描有数量上限、进度与取消。默认只列出，所有项目由用户选中。
3. 删除前重新校验路径、文件与父目录身份、大小和纳秒时间，复查运行中应用与打开文件。未知状态跳过。仅移入废纸篓，成功记录可撤销操作；显示失败原因与本地清理摘要。
4. UI 提供名称/类别/应用筛选、排序、200 行分页、跨页选择、双击打开、右键预览/新页签定位、忽略文件或目录、中英双语、页签恢复。
5. 回归：沙盒规则与边界测试、ZIP 安装包识别、硬链接/符号链接/文件替换、运行与占用保护、取消/上限/失败/撤销、分页筛选选择、导航恢复、本地化；执行完整逻辑测试、双架构构建与真实界面验收。

边界：不扫描系统根目录、不提权、不清空废纸篓；应用卸载、系统服务优化和二进制瘦身另行设计。忽略列表与历史仅存本机。文件大小与磁盘占用分开显示，移入废纸篓不会立即释放磁盘空间；APFS 共享块下占用为估算。

## 本次验收结果

- `native/build_native.sh --in-place --quick`：arm64、x86_64 构建与通用二进制合并成功，签名、资源及 7-Zip 引擎校验通过。
- 对生成应用分别执行 `arch -arm64 ... --run-tests --skip-device-tests` 与 `arch -x86_64 ... --run-tests --skip-device-tests`：各 872 项通过、0 项失败。未对真实安卓设备执行读写操作。
- 本次新增通用清理回归包含缓存/日志/沙盒/浏览器/ZIP 分类、年龄及范围、路径边界、符号链接和硬链接、运行中应用与未知占用状态、文件替换及复查时写入、扫描与探测上限/取消、200 行分页、连续切换排序、跨页选择、忽略持久化、清理页导航恢复及新页签定位。
- 模型集成测试使用专属临时目录生成一个安装包，实际移入废纸篓、验证历史成功数量，再通过现有全局撤销恢复。其它删除边界测试均注入临时目录移动函数。
- 原有微信清理、安卓解析、文件操作、收藏拖放、解压与语言切换回归保留。

所有清理测试只使用生成的测试文件；官网分支和部署配置不变。

- 既有真实界面页签冒烟测试：全部通过（按脚本有效断言，离屏合成点击中仅记录的诊断不计入结论）。
- 中文示例窗口实测：右键菜单、忽略/取消忽略、重扫后的数量和占用、名称筛选、全选统计、清理系统弹窗及取消、内置文件夹选择器及无效目录拒绝。
- 中英文常规与紧凑窗口快照已核对；英文参数移入“扫描设置”，避免窗口较窄时的控件挤压。

## 合并空间清理入口

侧边栏只保留最后一项「空间清理」，使用与其它入口一致的默认文字颜色。页面内的「通用清理 / 软件清理」切换将按软件清理作为空间整理的子范围；微信与其它应用继续在软件选择器中同级展示，原始标识与辅助项过滤保留。

两个子范围共享窗口标题、页签图标与侧边栏高亮；新会话按统一入口和子范围保存，旧微信/软件页签继续恢复到软件子范围。切换范围取消扫描并清空待确认清理清单，执行清理时禁止切换；点击当前入口保留正在查看的子范围。

合并入口的最终应用包：arm64 与 x86_64 各 911 项通过、0 项失败（跳过真实安卓设备）；新增回归覆盖清理时切换阻止、统一保存格式、旧会话迁移、子范围操作路由、清空确认、保留软件以及入口再次点击行为。

真实界面：页签冒烟测试全部通过；隔离目录验证通用扫描、全选占用、切换软件子范围、微信附件查看、返回通用后清除勾选。已保存通用与软件子范围截图，测试目录在窗口关闭后清理。
