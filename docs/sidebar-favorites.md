# 侧边栏个人收藏

## 拖动添加

从 WinFile 的详细信息列表或大图标视图，将本地文件夹拖到左侧个人收藏行、空收藏提示或底部「拖入文件夹以添加到个人收藏」区域。也接收访达提供的文件夹拖放。进入接收区域时高亮提示；放下后只写入收藏快捷入口，不复制、移动或删除源目录，也不跳转当前页签。

列表中的多选文件夹可一起拖动；图标视图按拖起的单个条目添加。重复目录不会重复写入。普通文件、应用包、安卓路径、失效或不可读取的目录不会加入，结果显示在状态栏。

## 使用 WinFile 自带选择器

以下入口均使用同一个应用内弹窗：侧边栏底部「添加文件夹」、收藏右键「添加文件夹…」、「管理侧边栏」以及设置里的收藏添加按钮。

- 双击文件夹进入，点击向上按钮返回父目录，主页图标返回用户主目录。
- 输入绝对路径、相对路径或 `~`，按回车或点击「前往」。
- 用筛选框查找当前目录中的文件夹；勾选「显示隐藏文件」可浏览隐藏目录。
- 点击选中子文件夹，使用 ⌘ 或 ⇧ 多选，再点击「添加 N 个文件夹」。不选子项时可「添加当前文件夹」。
- 取消只关闭弹窗；不会改变主页面目录或收藏。

弹窗使用独立目录模型，在后台读取当前层级；快速切换时忽略旧结果。保留用户当前浏览的路径形式（例如 `/tmp` 或目录符号链接），避免系统列目录时意外改成另一路径。确认添加时再次校验目录。

## 实现与验证

`FolderPickerModel.swift` / `FolderPickerSheet.swift` 管理目录浏览及弹窗；`SidebarFolderDrop.swift` 处理文件 URL 拖出、异步解码及落点；添加结果复用 `FSEngine.addFolders` 的校验、去重和持久化逻辑。

实测应用内选择器的双击导航、输入路径、多选、添加当前目录、取消和嵌套管理面板入口；用户手动拖动 Beta 测试目录成功加入收藏，诊断记录及持久化结果均已确认；另观察到普通文件拖入被拒绝，目录内容保持不变。自动化拖动未能完成系统落点，未将该自动化尝试算作通过。
