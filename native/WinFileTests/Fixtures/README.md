# Archive fixtures

`stored-rar5.rar` is the decoded `test_read_format_rar5_stored.rar.uu` from libarchive:
https://github.com/libarchive/libarchive/blob/master/libarchive/test/test_read_format_rar5_stored.rar.uu
It contains `helloworld.txt` with the text `hello libarchive test suite!` and a newline.
Source project and license: https://github.com/libarchive/libarchive/blob/master/COPYING
All other archives are generated by NativeTestSuite in temporary directories.

`legacy-rar4.rar` is the decoded `test_read_format_rar.rar.uu` from the same project, containing plain files, directories and a relative link. The libarchive copyright and license notice is included in libarchive-COPYING.txt.

`compressed-rar5.rar` is decoded from `test_read_format_rar5_compressed.rar.uu`; the expected 1200-byte data is independently reconstructed from the public test_read_format_rar5.c algorithm.
