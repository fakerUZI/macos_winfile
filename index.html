02 / 设备状态更清楚

暂时忙碌，
也知道该怎么恢复。

同一 USB 连接暂时不可用时，保留已识别的设备名称，显示当前占用状态。原目录保留，释放占用后自动恢复。

如提示占用，可完全退出「预览」「照片」「图像捕捉」或其他传输软件；仅关闭窗口可能仍占用设备。WinFile 会自动重试。

03 / MTP 视频按需播放

从手机读视频，
不用先存一整份。

双击使用内置播放器，空格先预览，拖动进度按需读取。共享视频数据缓存上限 32 MiB，不创建完整视频磁盘副本。

32 MiB 仅指视频数据缓存。编码与分段读取取决于系统和设备；不兼容时提示错误，由你决定是否手动下载。

STORAGE CLEANUP

空间花在哪，
先看清，再整理。

侧边栏底部，一个「空间清理」入口。通用清理集中查看缓存、日志、安装包、大文件、微信附件与百度网盘下载；软件清理按应用缩小范围。

  • 占用、候选、筛选与已选文件，分别统计
  • 按应用名称、文件类型、文件名或路径筛选
  • 默认不勾选，先预览再确认移到废纸篓
  • 支持忽略目录，保留最近 7 天的缓存与日志

运行中的应用与受保护数据会跳过。占用为估算；移到废纸篓不会立即释放空间。

  • 全部、筛选与已选附件占用，一目了然

仅扫描本机附件，不读取或解密聊天数据库。达到扫描上限时标明部分结果，可提高上限重新扫描。

WinFile 免费吗？支持哪些 Mac？+

免费、MIT 协议开源。需要 macOS {{MIN_MACOS}} 或更新版本，同一个安装包支持 Apple 芯片和 Intel Mac。界面支持简体中文与英文。

第一次打开，提示无法验证开发者怎么办？+

当前发行包尚未经过 Apple 公证。请从本页的 GitHub Releases 下载，解压后将 WinFile.app 放入「应用程序」。核对 SHA-256 校验文件后，可按 macOS 提示到「系统设置 → 隐私与安全性」允许打开。查看完整安装说明 ↗

空间清理会自动删除文件吗？可以撤销吗？+

不会。扫描只列出候选，默认不选择任何文件，确认后才移到废纸篓；执行前会复查文件身份和占用状态，运行中的应用、受保护或无法确认状态的文件会保留。通用清理和其他软件缓存可在当前会话用 ⌘Z 撤销，微信附件可从废纸篓恢复。移到废纸篓不会立即增加可用空间；磁盘占用仅作估算。

为什么有些软件没有出现在软件清理列表？+

列表根据本机可读取的清理目录生成，不是所有已安装软件的清单。辅助、更新和扩展子程序不会单独列出。微信扫描本机附件；百度网盘还支持实际下载目录，可手动指定并保存。其他软件仅扫描已识别的缓存和日志，保留账号资料、配置、数据库及离线内容。新增目录后可点击「刷新软件列表」。

百度网盘的下载文件没找到怎么办？+

进入「空间清理 → 软件清理」，选择百度网盘后指定实际下载目录。常见位置会自动识别，自定义目录会保存。通用清理也会使用这个目录；只扫描已下载到本机的文件，执行清理前请先核对需要保留的内容。

微信清理能看到所有聊天文件吗？会删除聊天记录吗？+

只扫描已下载到这台 Mac 的附件及可识别缓存，不读取或解密聊天数据库。手机独有、尚未下载到 Mac 的文件不会显示。可添加自定义附件目录；文件时间筛选依据修改时间。请先预览和核对需要保留的附件，确认清理后所选文件会移到废纸篓。

连接安卓设备，需要先做什么？+

解锁手机或平板，用支持数据传输的 USB 线连接，选择「文件传输」，按提示允许访问。无需 USB 调试、ADB 或额外工具；WinFile 会自动识别插拔。可见范围由设备决定，Android/data 和应用私有目录可能不可见。如果设备提示被占用，请完全退出「预览」「照片」「图像捕捉」或其他传输软件，仅关闭窗口可能不会释放 USB 接口；WinFile 会自动重试。查看连接说明 ↗

安卓图片和 PDF 怎样打开？+

从 1.4.1 起，双击或右键打开安卓图片和 PDF，默认使用 WinFile 内置 Quick Look；空格也可预览。文件经校验后使用可复用的只读本机副本，修改不会自动回传到设备。需要用外部应用打开或编辑，请先手动下载。

这次修复避免自动启动外部「预览」及相机导入进程后占用 MTP 的 USB 接口。若你主动打开了外部相机导入或传输应用，仍可能发生设备独占；完全退出占用应用后，WinFile 会自动恢复。

打开安卓视频，会先下载完整文件吗？+

不会。内置播放器按需从 MTP 读取字节范围，使用上限 32 MiB 的共享视频数据缓存，不保存完整视频文件。关闭或断连时取消读取并释放缓存；这不是应用总内存上限，也不代表系统交换内存完全不写盘。编码或设备不兼容时明确报错，不自动下载回退。

其它文档仍需只读本机副本，缓存目标为 2 GiB / 7 天，在准备文件时清理；当前会话打开过的副本会保留给外部应用，可能超过目标。外部播放器或不支持的格式，请手动下载；手动下载的文件不会自动删除。

支持哪些解压格式？会覆盖已有文件吗？+

支持 ZIP、RAR（含 RAR5）、7Z、TAR，以及 GZip、BZip2、XZ 单文件和 TAR 组合格式，并支持密码和分卷。解压先在暂存目录完成，同名冲突会自动另存，不覆盖已有文件。创建压缩包目前支持 ZIP。

以后怎样更新？+

从 v1.2.0 起，WinFile 支持启动时检查更新。你可以安装、跳过某个版本或下次再说；也可以在应用中手动检查。更新包与更新源经过 Ed25519 签名校验。更早版本请先从 GitHub 手动升级一次。
