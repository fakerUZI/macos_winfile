WinFile 免费吗？支持哪些 Mac？+

免费、MIT 协议开源。需要 macOS {{MIN_MACOS}} 或更新版本，同一个安装包支持 Apple 芯片和 Intel Mac。界面支持简体中文与英文。

第一次打开，提示无法验证开发者怎么办？+

当前发行包尚未经过 Apple 公证。请从本页的 GitHub Releases 下载，解压后将 WinFile.app 放入「应用程序」。核对 SHA-256 校验文件后，可按 macOS 提示到「系统设置 → 隐私与安全性」允许打开。查看完整安装说明 ↗

空间清理会自动删除文件吗？可以撤销吗？+

不会。扫描只列出候选，默认不选择任何文件，确认后才移到废纸篓；执行前会复查文件身份和占用状态，运行中的应用、受保护或无法确认状态的文件会保留。通用清理和其他软件缓存可在当前会话用 ⌘Z 撤销，微信附件可从废纸篓恢复。移到废纸篓不会立即增加可用空间；磁盘占用仅作估算。

为什么有些软件没有出现在软件清理列表？+

列表根据本机可读取的清理目录生成，不是所有已安装软件的清单。没有识别到缓存或日志目录的软件，以及辅助、更新和扩展子程序，不会列出。微信使用独立的本机附件扫描；其他软件仅扫描已识别的缓存和日志，不处理账号资料、配置、数据库或离线内容。新增目录后可点击「刷新软件列表」。

微信清理能看到所有聊天文件吗？会删除聊天记录吗？+

只扫描已下载到这台 Mac 的附件及可识别缓存，不读取或解密聊天数据库。手机独有、尚未下载到 Mac 的文件不会显示。可添加自定义附件目录；文件时间筛选依据修改时间。请先预览和核对需要保留的附件，确认清理后所选文件会移到废纸篓。

连接安卓设备，需要先做什么？+

先安装 Android Platform Tools（adb），用 USB 连接设备，启用 USB 调试并在设备上确认授权。WinFile 会在侧边栏列出设备。部分系统目录（如 Android/data）可能受安卓权限限制。查看连接说明 ↗

支持哪些解压格式？会覆盖已有文件吗？+

支持 ZIP、RAR（含 RAR5）、7Z、TAR，以及 GZip、BZip2、XZ 单文件和 TAR 组合格式，并支持密码和分卷。解压先在暂存目录完成，同名冲突会自动另存，不覆盖已有文件。创建压缩包目前支持 ZIP。

以后怎样更新？+

从 v1.2.0 起，WinFile 支持启动时检查更新。你可以安装、跳过某个版本或下次再说；也可以在应用中手动检查。更新包与更新源经过 Ed25519 签名校验。更早版本请先从 GitHub 手动升级一次。
