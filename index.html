01 / 包内文件默认打开

选好文件，
双击交给默认应用。

文本、Markdown、图片、视频，双击即可交给默认应用。优先使用 LeafFiles 指定的打开方式，未设置时跟随 macOS。

仅支持直接打开小于 64 MiB 的文件。达到限制、大小未知或链接会提示先解压；空格仍使用内置快速预览。

02 / 临时副本安心查看

只解出所选文件，
关掉窗口也能继续看。

无需手动解压整个压缩包。外部应用读取独立的只读缓存，关闭压缩包窗口后仍可继续查看；同一预览会话重复打开会复用副本。

修改不会写回原压缩包。旧会话缓存会在后续打开文件时按期限与容量清理；密码重试、取消和打开失败均有明确提示。

页签菜单只留一个下三角，更多操作保留省略号。新建、复制为和紧凑显示菜单统一样式，去掉重复箭头。

保留 macOS 原生配色，原有功能、快捷键、收藏和设置继续沿用。安装仍使用顶部的终端命令。

STORAGE CLEANUP

空间花在哪，
先看清，再整理。

侧边栏底部，一个「空间清理」入口。通用清理集中查看缓存、日志、安装包、大文件、微信附件与百度网盘下载；软件清理按应用缩小范围。

  • 占用、候选、筛选与已选文件，分别统计
  • 按应用名称、文件类型、文件名或路径筛选
  • 默认不勾选，先预览再确认移到废纸篓
  • 支持忽略目录，保留最近 7 天的缓存与日志

运行中的应用与受保护数据会跳过。占用为估算；移到废纸篓不会立即释放空间。

WECHAT ATTACHMENTS

微信占了多少，
先看清，再清理。

在「通用清理」中查看微信附件，或进入「软件清理 → 微信」，按账号、月份、类型和大小进一步筛选。手动添加的微信目录也会用于通用扫描。

  • 全部、筛选与已选附件占用，一目了然
  • 按账号、月份和来源，进一步缩小范围
  • 双击打开，或在新页签进入所在文件夹
  • 确认后移到废纸篓，清理由你决定

仅扫描本机附件，不读取或解密聊天数据库。达到扫描上限时标明部分结果，可提高上限重新扫描。

ANDROID FILES

安卓连上 Mac，
文件也就连上了。

用 USB 连接手机或平板，选择「文件传输」，在熟悉的列表里浏览 MTP 共享存储。相片、下载和文档，各在其位。

  • 插拔自动刷新，从侧边栏进入设备
  • 上传、下载，双向传输文件
  • 新建、重命名和复制；移动需设备支持
  • 视频内置播放，支持预览与拖动进度

无需 USB 调试或 ADB。图片与 PDF 在应用内预览，其它文档交给默认应用，均使用只读本机副本；视频按需读入内存。私有目录、编码与分段读取受系统和设备限制。

ARCHIVE PREVIEW & EXTRACTION

先看清内容，
再把文件解出来。

ZIPX、RAR、7Z、TAR 与更多归档格式，都在一个窗口里处理。先浏览目录或搜索，再双击小文件交给默认应用，或按空格快速预览。

ZIP / ZIPXRAR / RAR57Z / TARZSTD / LZMACAB / ARJ / LZH
  • 目录与面包屑导航，全包搜索显示完整路径
  • 双击用默认应用打开，空格保留快速预览
  • 密码、分卷、批量解压与取消
  • 同名冲突自动另存，保留已有文件

创建压缩包支持 ZIP。默认应用打开需小于 64 MiB，达到限制或大小未知时请先解压；内置预览上限 64 MiB，压缩 TAR 中间归档上限 512 MiB。外部打开副本延后清理，不写回压缩包；算法变体受引擎限制。

WinFile 和 LeafFiles 是同一款应用吗？+

是的，WinFile 已更名为 LeafFiles。从 v2.0.1 起，应用目录也统一为 LeafFiles.app。使用本页顶部的终端安装命令，会备份并迁移旧 WinFile.app，保留收藏、设置和自动更新渠道。应用内更新可能保留旧目录名；退出应用后重新运行安装命令即可迁移。部分历史截图仍显示旧名称。

LeafFiles 免费吗？支持哪些 Mac？+

免费、MIT 协议开源。需要 macOS {{MIN_MACOS}} 或更新版本，同一个安装包支持 Apple 芯片和 Intel Mac。界面支持简体中文与英文。

第一次打开，提示无法验证开发者怎么办？+

请先使用本页顶部的终端命令安装。脚本会校验安装包摘要与应用签名，保留旧版本备份，安装失败时回滚。当前应用尚未经过 Apple 公证；如 macOS 仍提示无法验证开发者，可到「系统设置 → 隐私与安全性」按系统提示允许打开。查看终端安装命令 ↑

空间清理会自动删除文件吗？可以撤销吗？+

不会。扫描只列出候选，默认不选择任何文件，确认后才移到废纸篓；执行前会复查文件身份和占用状态，运行中的应用、受保护或无法确认状态的文件会保留。通用清理和其他软件缓存可在当前会话用 ⌘Z 撤销，微信附件可从废纸篓恢复。移到废纸篓不会立即增加可用空间；磁盘占用仅作估算。

为什么有些软件没有出现在软件清理列表？+

列表根据本机可读取的清理目录生成，不是所有已安装软件的清单。辅助、更新和扩展子程序不会单独列出。微信扫描本机附件；百度网盘还支持实际下载目录，可手动指定并保存。其他软件仅扫描已识别的缓存和日志，保留账号资料、配置、数据库及离线内容。新增目录后可点击「刷新软件列表」。

百度网盘的下载文件没找到怎么办？+

进入「空间清理 → 软件清理」，选择百度网盘后指定实际下载目录。常见位置会自动识别，自定义目录会保存。通用清理也会使用这个目录；只扫描已下载到本机的文件，执行清理前请先核对需要保留的内容。

微信清理能看到所有聊天文件吗？会删除聊天记录吗？+

只扫描已下载到这台 Mac 的附件及可识别缓存，不读取或解密聊天数据库。手机独有、尚未下载到 Mac 的文件不会显示。可添加自定义附件目录；文件时间筛选依据修改时间。请先预览和核对需要保留的附件，确认清理后所选文件会移到废纸篓。

连接安卓设备，需要先做什么？+

解锁手机或平板，用支持数据传输的 USB 线连接，选择「文件传输」，按提示允许访问。无需 USB 调试、ADB 或额外工具；LeafFiles 会自动识别插拔。可见范围由设备决定，Android/data 和应用私有目录可能不可见。如果设备提示被占用，请完全退出「预览」「照片」「图像捕捉」或其他传输软件，仅关闭窗口可能不会释放 USB 接口；LeafFiles 会自动重试。查看连接说明 ↗

安卓图片和 PDF 怎样打开？+

从 1.4.1 起，双击或右键打开安卓图片和 PDF，默认使用 LeafFiles 内置 Quick Look；空格也可预览。文件经校验后使用可复用的只读本机副本，修改不会自动回传到设备。需要用外部应用打开或编辑，请先手动下载。

这次修复避免自动启动外部「预览」及相机导入进程后占用 MTP 的 USB 接口。若你主动打开了外部相机导入或传输应用，仍可能发生设备独占；完全退出占用应用后，LeafFiles 会自动恢复。

打开安卓视频，会先下载完整文件吗？+

不会。内置播放器按需从 MTP 读取字节范围，使用上限 32 MiB 的共享视频数据缓存，不保存完整视频文件。关闭或断连时取消读取并释放缓存；这不是应用总内存上限，也不代表系统交换内存完全不写盘。编码或设备不兼容时明确报错，不自动下载回退。

其它文档仍需只读本机副本，缓存目标为 2 GiB / 7 天，在准备文件时清理；当前会话打开过的副本会保留给外部应用，可能超过目标。外部播放器或不支持的格式，请手动下载；手动下载的文件不会自动删除。

支持哪些解压格式？会覆盖已有文件吗？+

支持 ZIP/ZIPX、RAR（含 RAR5）、7Z、TAR、CAB、ARJ、LZH/LHA、CPIO、AR、DEB、RPM、XAR，以及 GZip、BZip2、XZ、Zstandard、LZMA、Unix compress 单文件和 TAR 组合格式；支持密码、分卷、批量和取消。解压先在暂存目录完成，同名冲突自动另存。具体算法和加密变体由引擎决定，不能保证所有 ZIPX 专有算法；软件包不执行安装。创建压缩包仍支持 ZIP。

能先看压缩包里的内容，再解压吗？+

可以。双击本机压缩包、按空格或右键「预览压缩包」，使用目录、面包屑和上一级浏览，或搜索整个压缩包。双击包内文件或点击「用默认应用打开」，优先使用 LeafFiles 指定的文件关联，否则使用 macOS 默认应用。仅直接打开小于 64 MiB 的文件，达到限制、大小未知或链接会提示先解压。单击只选中；空格和「查看所选文件」继续使用内置 Quick Look。底部「解压全部」可选择保存位置，当前不支持只解压选中项。

普通包列目录不解出文件。打开所选文件会临时解出只读副本，修改不会写回压缩包；外部应用副本在关闭压缩包窗口后仍保留，同一预览会话可复用，后续打开文件时按 7 天和 512 MiB 目标清理旧会话缓存。本次运行中已交给外部应用的文件受保护，容量目标不是硬上限。内置预览副本关闭后清理。压缩 TAR 中间归档上限 512 MiB，目录列表上限 100,000 项 / 32 MiB。

以后怎样更新？+

从 v1.2.0 起，LeafFiles 支持启动时检查更新。你可以安装、跳过某个版本或下次再说；也可以在应用中手动检查。更新包与更新源经过 Ed25519 签名校验。更早版本可使用本页顶部的终端安装命令升级。
