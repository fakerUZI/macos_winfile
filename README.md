# WinFile 产品官网

[访问官网](https://fakeruzi.github.io/macos_winfile/) · [下载最新版](https://github.com/fakerUZI/macos_winfile/releases/latest) · [应用源码](https://github.com/fakerUZI/macos_winfile/tree/main)

原生 macOS 文件管理器，提供空间清理、按软件清理、微信附件整理、安卓文件管理、多格式解压、多页签与个人收藏。当前介绍正式版 v1.4.0：安卓统一采用 MTP，插拔自动识别，视频通过内置播放器按需读取，32 MiB 共享视频数据缓存，无完整视频磁盘副本。普通文档仍使用只读本机缓存；兼容性与缓存规则见中英文页面说明。

中文与英文页面均保留清新绿色视觉和右上角语言切换。空间清理截图沿用 v1.3.0 示例并明确标注；MTP 文件管理与视频截图来自真实设备上的生成测试文件，不含私人文件内容。
