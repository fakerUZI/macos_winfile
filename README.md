# LeafFiles 产品官网

[访问官网](https://fakeruzi.github.io/macos_winfile/) · [下载最新版](https://github.com/fakerUZI/macos_winfile/releases/latest) · [应用源码](https://github.com/fakerUZI/macos_winfile/tree/main)

LeafFiles（原 WinFile）是免费开源的原生 macOS 文件管理器，提供空间清理、微信附件整理、MTP 安卓文件管理、多格式解压、多页签与个人收藏。当前介绍正式版 v2.0.0，重点呈现界面优化与 WinFile 更名为 LeafFiles。

中文与英文页面均保留清新绿色视觉、首页顶部一键安装命令和右上角语言切换。首页界面优化截图使用隔离示例文件。压缩包预览截图来自真实应用功能验收中的生成样例；空间清理截图保留 v1.3.0 标注，MTP 截图来自真实设备的生成样例，不含私人文件内容。预览大小、算法与设备限制见页面说明。

原一键安装命令、GitHub 地址、下载文件名与自动更新渠道保持不变，已有收藏与设置继续沿用。从 v2.0.0 起，应用显示名称为 LeafFiles；部分历史截图仍使用 WinFile 名称。

curl -fsSL https://raw.githubusercontent.com/fakerUZI/macos_winfile/main/install.sh | /bin/bash
