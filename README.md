# WinFile 产品官网

[访问官网](https://fakeruzi.github.io/macos_winfile/) · [下载最新版](https://github.com/fakerUZI/macos_winfile/releases/latest) · [应用源码](https://github.com/fakerUZI/macos_winfile/tree/main)

原生 macOS 文件管理器，提供空间清理、微信附件整理、MTP 安卓文件管理、多格式解压、多页签与个人收藏。当前介绍正式版 v1.5.0：新增 ZIPX 与更多解压格式、包内目录与单文件预览，以及预览窗口中的内置目录选择器和解压入口。保留安卓图片/PDF 内置预览与视频按需读取、32 MiB 共享视频数据缓存。

中文与英文页面均保留清新绿色视觉、首页顶部一键安装命令和右上角语言切换。压缩包预览截图来自真实应用功能验收中的生成样例；空间清理截图保留 v1.3.0 标注，MTP 截图来自真实设备的生成样例，不含私人文件内容。预览大小、算法与设备限制见页面说明。
